## ১. ওয়ান-স্টপ মাস্টার হ্যান্ডনোট

### ১.১ স্থানাঙ্ক ও দূরত্ব
- **দূরত্ব:** d = √((x₁−x₂)² + (y₁−y₂)²)। (3,2)–(−4,−2) ⇒ **√65**; (−3,−1)–(−3,−5) ⇒ **4**।
- **বিভক্তিকরণ (m : n অনুপাতে):** অন্তঃ — ((mx₂ + nx₁)/(m+n), (my₂ + ny₁)/(m+n)); বহিঃ — ((mx₂ − nx₁)/(m−n), (my₂ − ny₁)/(m−n))।
- **মধ্যবিন্দু** ((x₁+x₂)/2, (y₁+y₂)/2)। **ত্রিখণ্ডক বিন্দু:** 1:2 ও 2:1 অনুপাতে।
  - [Engg] (1,2) ও (13,−18) এর সংযোজক রেখার সমচতুর্থাংশক বিন্দু: মধ্যবিন্দু (7,−8); অপর দুটি **(4,−3)** ও **(10,−13)**।
- **ভরকেন্দ্র (centroid)** G = ((x₁+x₂+x₃)/3, (y₁+y₂+y₃)/3)।
- **লম্ববিন্দু (H), ভরকেন্দ্র (G), পরিকেন্দ্র (O) সমরেখ; G, HO-কে 2:1 অনুপাতে বিভক্ত করে (H থেকে G = 2, G থেকে O = 1)** ⇒ **G = (H + 2O)/3**।
  - H(7,−1), G(21,1) ⇒ O = (3G − H)/2 = **(28, 2)**।
  - G(20,−3), O(24,−6) ⇒ H = 3G − 2O = **(12, 3)**।
- **সামান্তরিকের চতুর্থ শীর্ষ:** A + C = B + D। (3,−4), (−6,5), (−2,−1) ⇒ **(3−2+6, −4−1−5) = (7, −10)**।
- **ত্রিভুজের ক্ষেত্রফল** = ½|x₁(y₂−y₃) + x₂(y₃−y₁) + x₃(y₁−y₂)|।
  - x = 0, x = y, 5x − y + 1 = 0 দ্বারা গঠিত ত্রিভুজ ⇒ শীর্ষ (0,1), (−¼,−¼), (0,0) ⇒ **ক্ষেত্রফল = 1/8**।
- **সমরেখ হওয়ার শর্ত:** ক্ষেত্রফল = 0 বা ঢাল সমান।
  - (3,−9), (b+5,b−1), (b+2,b) ⇒ **b = −13/2**।
  - (2,1), (a+1,a+3), (a−2,−a) ⇒ 2a² − 2a − 9 = 0 ⇒ **a = (1 ± √19)/2**।
  - (t+1,1), (2t+1,3), (2t+2,2t) ⇒ 2t² − 3t − 2 = 0 ⇒ **t = 2 বা −½** (বিন্দু: t = 2 ⇒ (3,1), (5,3), (6,4); t = −½ ⇒ (½,1), (0,3), (1,−1))।
  - (0,0), (sinθ, cosθ), (tanθ, cotθ) সমরেখ ⇒ cosθ − sinθ = 0 ⇒ tanθ = 1 ⇒ π < θ < 3π/2 হলে **θ = 5π/4**।

### ১.২ পোলার ↔ কার্তেসীয়
- **x = r cosθ, y = r sinθ; r² = x² + y²; tanθ = y/x**।
- **চতুর্ভাগ দেখে θ ঠিক করো:**
  - (−3√3, −3): r = 6; x < 0, y < 0 ⇒ **৩য় চতুর্ভাগ** ⇒ θ = π + tan⁻¹(1/√3) = 7π/6 = **210°** ⇒ **(6, 210°)**।
  - (3, 150°) ⇒ x = 3 cos150° = **−3√3/2**; y = 3 sin150° = **3/2**।
  - (3, 180°) ও (3√3, 270°) ⇒ (−3, 0), (0, −3√3) ⇒ ঢাল = (0+3√3)/(−3−0) = **−√3**।
- **কনিক/বক্ররেখা শনাক্তকরণ (পোলার → কার্তেসীয়):**
  - **r(1 + cosθ) = 2** ⇒ r = 2 − x ⇒ x² + y² = (2 − x)² ⇒ **y² + 4x = 4** (পরাবৃত্ত)।
  - **r sin²θ + sinθ − r = 0** ⇒ y²/r + y/r = r ⇒ y² + y = x² + y² ⇒ **x² = y** (পরাবৃত্ত)।
  - **r = sin(θ − 45°)** ⇒ √2 r² = r sinθ − r cosθ ⇒ **√2(x² + y²) = x − y** (বৃত্ত)।
  - **r² sin2θ = 36** ⇒ 2xy = 36 ⇒ **xy = 18** (আয়তাকার অধিবৃত্ত)।

### ১.৩ ঢাল ও সরলরেখার সমীকরণ
- **ঢাল m = tanθ = (y₂−y₁)/(x₂−x₁)**; ax+by+c = 0 এর ঢাল = **−a/b**।
- **x-অক্ষের ধনাত্মক দিকের সাথে** θ কোণ ⇒ m = tanθ (**ঋণাত্মক y-অক্ষের সাথে** কোণ দিলে সতর্ক)।
  - **y-অক্ষের সাথে π/3 কোণ (Varsity MCQ: "কোনটি y-অক্ষের সাথে ঘড়ির কাঁটার দিকে π/3 কোণ উৎপন্ন করে?")** ⇒ উত্তর **√3x − 3y − 7 = 0** (ঢাল +1/√3)। বইয়ের সমাধান-নীতি: **ধনাত্মক y-অক্ষের সাথে কোণ হলে ঢাল −1/√3; ঋণাত্মক y-অক্ষের সাথে কোণ হলে ঢাল +1/√3।** ⚠️ আগে ঠিক করো কোণ কোন অক্ষ ও কোন দিক থেকে মাপা।
  - √3y − x + 5 = 0 ⇒ ঢাল 1/√3 ⇒ **x-অক্ষের সাথে 30° ⇒ y-অক্ষের সাথে 60°**।
  - মূলবিন্দুগামী, x-অক্ষের সাথে 60° ⇒ y = √3x ⇒ **√3x − y = 0**।
  - (3,−2) বিন্দুগামী, 135° ⇒ y + 2 = −(x − 3) ⇒ **x + y − 1 = 0**।
- **সমীকরণের রূপ:**
  | রূপ | সমীকরণ |
  |---|---|
  | ঢাল-বিন্দু | y − y₁ = m(x − x₁) |
  | দুই বিন্দু | (y−y₁)/(y₂−y₁) = (x−x₁)/(x₂−x₁) |
  | ছেদক (intercept) | x/a + y/b = 1 |
  | **লম্ব-রূপ (normal)** | **x cosα + y sinα = p (p > 0)** |
  | **প্যারামিতিক/দূরত্ব রূপ** | (x−x₁)/cosθ = (y−y₁)/sinθ = ±r |
- **x/a + y/b = 1 ⇒ লম্ব দূরত্ব ও ক্ষেত্রফল:** অক্ষদ্বয়ের সাথে গঠিত ত্রিভুজের ক্ষেত্রফল = ½|ab|। **x/6 + y/5 = 1 ⇒ ক্ষেত্রফল = 15**।
- **3x + √3y + 2 = 0 ও x cosα + y sinα = p অভিন্ন (p > 0)**: √(9+3) = √12 দিয়ে ভাগ ⇒ −3/(2√3)… দুই পাশ তুলনা করে **p = 1/√3** এবং cosα, sinα উভয় ঋণাত্মক ⇒ **α = 210°**।
- **সমান্তরাল রেখা:** ax + by + k = 0 (শুধু ধ্রুবক পদ বদলায়)। **3x + 7y − 2 = 0-এর সমান্তরাল (2,1)-গামী** ⇒ 3x + 7y + k = 0 ⇒ k = −13 ⇒ **3x + 7y − 13 = 0**। 2x + 3y + 4 = 0-এর সমান্তরাল (3,2)-গামী ⇒ **2x + 3y − 12 = 0**।
- **লম্ব রেখা:** bx − ay + k = 0 (m₁m₂ = −1)।
- **অক্ষের সমান্তরাল রেখা:** x-অক্ষের সমান্তরাল ⇒ **y = c**; y-অক্ষের সমান্তরাল ⇒ **x = c**।
  - x + y = 5 ও y − x = 1-এর ছেদবিন্দু (2,3) ⇒ **y-অক্ষের সমান্তরাল রেখা x = 2** (x-অক্ষের সমান্তরাল চাইলে y = 3)।
  - x + 3y − 1 = 0 ও 2x + y + 5 = 0-এর ছেদবিন্দুগামী, **x-অক্ষের সমান্তরাল** ⇒ ছেদবিন্দু (−16/5, 7/5) ⇒ **y = 7/5 ⇒ 5y − 7 = 0**।
- **x-অক্ষ/y-অক্ষ সাপেক্ষে প্রতিবিম্ব:** 12x + 9y + 16 = 0 এর **x-অক্ষ সাপেক্ষে প্রতিবিম্বের ঢাল** ⇒ (y → −y) 12x − 9y + 16 = 0 ⇒ ঢাল **4/3**; 12x − 9y + 16 = 0 এর ⇒ **−4/3**।

### ১.৪ লম্ব দূরত্ব ও সমান্তরাল রেখার দূরত্ব
- **বিন্দু থেকে রেখার দূরত্ব = |ax₁ + by₁ + c| / √(a² + b²)**।
  - মূলবিন্দু থেকে 3x + 4y = 5 ⇒ |−5|/5 = **1**।
  - (−2, 3) থেকে x − y = 5 ⇒ |−2 − 3 − 5|/√2 = **5√2**।
- **সমান্তরাল রেখার দূরত্ব = |c₁ − c₂| / √(a² + b²)** (**x ও y-এর সহগ একই থাকতে হবে**)।
  - y = x + 4 ও y = x ⇒ x − y + 4 = 0, x − y = 0 ⇒ **4/√2 = 2√2**।
  - x + 2y + 1 = 0 ও x + 2y = 4 ⇒ x + 2y − 4 = 0 ⇒ |1 − (−4)|/√5 = **√5**।
- **x = 2, x = 4, y = 4, y = 6 দ্বারা গঠিত বর্গক্ষেত্রের কর্ণ:** **AC: x − y + 2 = 0; BD: x + y − 8 = 0**।
- **ত্রিভুজের উচ্চতা:** A(−3,−2), B(−3,9), C(5,−8) ⇒ CA: 6x + 8y + 34 = 0 ⇒ B থেকে লম্ব দূরত্ব = |−18 + 72 + 34|/10 = **44/5**।
- **y = 3x রেখা, ∆AOP = 6**: P(x, 3x), ক্ষেত্রফল = ½·x·3x = 6 ⇒ x = 2 ⇒ **AP = 6**।
- **ত্রিভুজের পরিকেন্দ্র/লম্ববিন্দু সংযোগ:** উপরে ১.১।
- **ঢালের লম্ব দূরত্বে রেখা:** ঢাল −2, মূলবিন্দু থেকে দূরত্ব 4 ⇒ 2x + y + k = 0 ⇒ |k|/√5 = 4 ⇒ **2x + y ± 4√5 = 0**।
- **একটি রেখার সাপেক্ষে নির্দিষ্ট দূরত্বে দুই বিন্দু:** 3x + 4y − 8 = 0 এর ওপর (4, −1) থেকে 5 একক দূরে ⇒ (x−4)/(4/5) = (y+1)/(−3/5) = ±5 ⇒ **(8, −4) ও (0, 2)**।
- **একটি বিন্দু থেকে নির্দিষ্ট দূরত্বে রেখার সংখ্যা:** (7,17)-গামী, (1,9) থেকে 6 একক দূরত্বে ⇒ ঢাল m = 7/24 এবং আরেকটি **x = 7** (ঢাল অসংজ্ঞায়িত) ⇒ **মোট 2টি** (⚠️ উল্লম্ব রেখা ভুলে গেলে 1টি পাবে)। সমীকরণ: **7x − 24y + 359 = 0** ও **x = 7**।

### ১.৫ দুই রেখার মধ্যবর্তী কোণ ও সমদ্বিখণ্ডক
- **tanθ = ± (m₁ − m₂)/(1 + m₁m₂)**; সমান্তরাল m₁ = m₂; লম্ব m₁m₂ = −1।
  - **y + 2 = 0 (x-অক্ষের সমান্তরাল, ঢাল 0) ও 2x + 1 = 0 (y-অক্ষের সমান্তরাল)** ⇒ মধ্যবর্তী কোণ **90°**।
  - **x + y = 0 ও 2y + 3 = 0** ⇒ ঢাল −1 ও 0 ⇒ কোণ **45° ও 135° উভয়ই সম্ভব ⇒ (b) ও (c) উভয়ই** — Varsity MCQ-তে উত্তর **"b ও c উভয়ই"**।
  - 6√3x − 18y + 5 = 0 (m₁ = 1/√3) ও 9x − 3√3y + 1 = 0 (m₂ = √3) ⇒ সূক্ষ্মকোণ **30°** ⇒ **স্থূলকোণ 150°**।
- **নির্দিষ্ট কোণ (45°/30°) করে এমন রেখা:** (−1,2)-গামী, 3x − y + 7 = 0 এর সাথে 45° ⇒ m₁ = 3; 1 = |3 − m₂|/|1 + 3m₂| ⇒ **m₂ = 1/2 বা −2** ⇒ **x − 2y + 5 = 0 ও 2x + y = 0**।
  - (2,6)-গামী, √3x − y + 2 = 0 এর সাথে 30°: m₂ = **1/√3** (⇒ x − √3y + 6√3 − 2 = 0) **এবং উল্লম্ব রেখা x = 2** (অসংজ্ঞায়িত ঢাল)।
  - **রম্বসের এক বাহু √3x − y + 1 = 0, কর্ণের সাথে 30°, কর্ণদ্বয়ের ছেদবিন্দু (4,2)** ⇒ কর্ণ **x − √3y + 2√3 − 4 = 0** ও **√3x + y − 4√3 − 2 = 0** (দুই কর্ণ পরস্পর লম্ব)।
- **কোণ সমদ্বিখণ্ডক:** **(a₁x + b₁y + c₁)/√(a₁²+b₁²) = ± (a₂x + b₂y + c₂)/√(a₂²+b₂²)**।
  - **কোন কোণ (স্থূল/সূক্ষ্ম)-এ বিন্দু P(x₁,y₁) আছে?**
    **(a₁x₁+b₁y₁+c₁)(a₂x₁+b₂y₁+c₂)(a₁a₂+b₁b₂) > 0 ⇒ স্থূলকোণ; < 0 ⇒ সূক্ষ্মকোণ।**
    - (1,2) বিন্দু, রেখা 4x−4y+3 = 0 ও x+7y−2 = 0: মান = (−1)(13)(−24)… ⇒ **> 0 ⇒ স্থূলকোণে** (Engg উত্তর)।
    - P(2,5), রেখা 2x+y+3 = 0 ও 3x−4y+7 = 0 ⇒ **−168 < 0 ⇒ সূক্ষ্মকোণে**; সূক্ষ্মকোণের সমদ্বিখণ্ডক: **(10 + 3√5)x + (5 − 4√5)y + (15 + 7√5) = 0**; মূলবিন্দু স্থূলকোণে (42 > 0)।
    - (4,−1) বিন্দু, y = −x + 2 ও y = x/7 − 3: **(4−1−2)×(4+7−21)×(1−7) = 60 > 0 ⇒ স্থূলকোণে**।
  - **উভয় অক্ষ থেকে সমান অংশ ছেদ না করা** ⇒ ঢাল **±1** হলে অক্ষদ্বয়ের সাথে 45° ⇒ সমান ছেদ। **4√3x − 2√3y ± 6 = 0-এর ঢাল 2 ⇒ 45° উৎপন্ন করে না ⇒ সমান ছেদ করে না** (Varsity MCQ)।
  - 4x − 4y + 3 = 0 ও x + 7y − 2 = 0: **স্থূলকোণ সমদ্বিখণ্ডক 24x + 8y + 7 = 0; সূক্ষ্মকোণ 16x − 48y + 23 = 0**।
  - (4,−1) বিন্দুর জন্য অন্তর্ভুক্ত: **সমদ্বিখণ্ডক: 4x + 12y + 11 = 0 (+) ও 6x − 2y − 31 = 0 (−)**।
- **একটি রেখা অপর রেখার সাপেক্ষে প্রতিফলিত (mirror):** L₂-এর L₁ সাপেক্ষে প্রতিবিম্ব: **(a₁² + b₁²)·L₂ = 2(a₁a₂ + b₁b₂)·L₁**।
  - x − 2y + 2 = 0 এর সাপেক্ষে x + y − 1 = 0-এর লম্ব/প্রতিফলন ⇒ **7x + y − 1 = 0**।
  - **আলোকরশ্মির প্রতিফলন [Engg]:** C(3,1) থেকে রশ্মি A(1,2) ও B(3,5)-গামী রেখায় A-তে আপতিত ⇒ প্রতিফলিত রশ্মির সমীকরণ **19x + 22y − 63 = 0**। P(1,−2) থেকে রশ্মি x = (y+1)/3 রেখায় Q(2,5)-এ আপতিত ⇒ প্রতিফলিত রশ্মি **31x − 17y + 23 = 0**।
- **ABC ত্রিভুজের অন্তঃকেন্দ্র O:** AB: x − 7y + 5 = 0, AO: x + 3y − 2 = 0 ⇒ AC এর ঢাল −1 ⇒ **AC: 5x + 5y = 3**।

### ১.৬ ছেদবিন্দুগামী রেখা ও সমবিন্দুগামিতা
- L₁ + kL₂ = 0 ⇒ L₁ ও L₂-এর ছেদবিন্দুগামী যেকোনো রেখা।
  - **মূলবিন্দু ও x+2y−3 = 0, x−y = 4-এর ছেদবিন্দুগামী:** k = −3/4 ⇒ **x + 11y = 0**।
- **তিন রেখা সমবিন্দুগামী:** নির্ণায়ক |a₁ b₁ c₁; a₂ b₂ c₂; a₃ b₃ c₃| = 0।
  - x + y + 3 = 0, 2x + 3y + 8 = 0 ছেদ (−1,−2); ax + by − 7 = 0-এ বসালে **−a − 2b − 7 = 0 ⇒ a + 2b = −7**।
- **অমীমাংসিত/অসীম সমাধান:** x − y = 3, 2x − 2y = k ⇒ **k = 6** (সহগ সমানুপাতিক)।
- **x + (1−a)y = a ⟂ (0,b) ও (2,2)-এর সংযোজক রেখা** ⇒ m₁m₂ = −1 ⇒ **2a − b = 0**; **সমান্তরাল হলে 2a + b = 4** (Set B)।
- **x + (1−a)y = 1, (b,0) ও (2,2)** সমান্তরাল ⇒ **2a + b = 4**।

### ১.৭ সঞ্চারপথ (Locus)
- **মই (ladder) সমস্যা:** x cosα/a + y sinα/b = sin2α … মই-এর মধ্যবিন্দুর সঞ্চারপথ **x²/a² + y²/b² = 1** (Engg: বিড়াল মাঝখানে ⇒ বৃত্ত/উপবৃত্ত)।
  - **(2:1 অনুপাতে বিভক্ত) বিড়াল:** **9x²/(4a²) + 9y²/(16b²) = 1**।
  - **দণ্ড 20 m, দেওয়াল থেকে পাদবিন্দুর দূরত্ব 5√3 m (পিঁপড়ার সঞ্চারপথ):** sin2θ = ±√3/2 ⇒ θ = π/6, π/3 ⇒ **√3x + y = 10√3** ও **x + √3y = 10√3**।
- **সঞ্চারপথ নির্ণয়ের ধাপ:** (১) চলমান বিন্দু P(x,y); (২) শর্ত লেখো; (৩) প্যারামিটার (θ, α, t) বাদ দাও।

### ১.৮ যোগাশ্রয়ী প্রোগ্রাম (Linear Programming)
- **সিদ্ধান্ত চলক:** x, y ≥ 0 (অঋণাত্মক ⇒ **শূন্য বা ধনাত্মক**)।
- **উদ্ভাবন:** **1939 সালে** (Kantorovich) — Varsity MCQ-তে উত্তর **"কোনোটিই নয়"** (1945, 1949, 1938 অপশনে নেই) ⇒ ⚠️ অপশন (a) 1945, (b) 1949, (c) 1938 ভুল।
- **ধাপ:** (১) চলক ধরো; (২) উদ্দেশ্য ফাংশন z; (৩) শর্ত → অসমতা; (৪) অনুকূল এলাকা আঁকো; (৫) **কোণ বিন্দুতে z-এর মান**; (৬) সর্বোচ্চ/সর্বনিম্ন নাও।
- **লেখচিত্রে বিন্দু বের করা:** ax + by = c ⇒ x/(c/a) + y/(c/b) = 1; উদাহরণ: x + y = 5 ⇒ (5,0), (0,5); 4x + 2y = 12 ⇒ x/3 + y/6 = 1 ⇒ (3,0), (0,6)।
- **ছায়া-ঘেরা অঞ্চল সম্ভাব্য অঞ্চল হলে শর্ত:** **x/5 + y/6 ≤ 1 ⇒ 6x + 5y ≤ 30; x, y ≥ 0** (⚠️ ≥ 0 লেখো, > 0 নয়)।
- **সমাধান উদাহরণ:**
  1. **x + 2y ≤ 10, x + y ≤ 6, x ≤ 4, x,y ≥ 0; z = 2x + 3y** ⇒ কোণ বিন্দু (0,0), (4,0), (4,2), (2,4), (0,5) ⇒ z = 0, 8, 14, **16**, 15 ⇒ **z_max = 16 at (2,4)**।
  2. **x ≥ 0, y ≥ 0, x + y ≤ 5, x + 2y ≥ 8; z = 2x − y** ⇒ কোণ বিন্দু (0,5), (0,4), (2,3) ⇒ z = −5, −4, 1 ⇒ **z_min = −5**।
  3. **A, B দ্রব্য:** শ্রম 10, 6; কাঁচামাল 6, 18; লাভ 10, 12 টাকা; সর্বোচ্চ শ্রম 480, কাঁচামাল 864 ⇒ z = 10x + 12y; **(24, 40)** ⇒ **z_max = 720**।
  4. **ক্ষুদ্রতম দুই-অঙ্কের সংখ্যা** (অঙ্কদ্বয়ের যোগফল ≥ 12 এবং যেকোনোটির সাথে 2 যোগ করলেও এক অঙ্ক): x + y ≥ 12, x + 2 ≤ 9 ⇒ x ≤ 7, y ≥ 5 ⇒ ক্ষুদ্রতম **57**।
  5. **ছাপাখানা (রৈখিক ফাংশন):** 100 বই 12000 টাকা, 150 বই 16000 টাকা ⇒ ঢাল = 4000/50 = 80 ⇒ y − 12000 = 80(x − 100) ⇒ **200 বই = 20000 টাকা**।
