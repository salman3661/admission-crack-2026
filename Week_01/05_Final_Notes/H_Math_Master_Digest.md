## ১. ওয়ান-স্টপ কোর থিওরি ও অ্যাডভান্সড ফর্মুলা ম্যাট্রিক্স

### ১.১ কার্তেসীয় ও পোলার স্থানাঙ্ক এবং রূপান্তর
- **স্থানাঙ্ক রূপান্তর সমীকরণ:**
  $$x = r\cos\theta, \quad y = r\sin\theta, \quad r^2 = x^2 + y^2, \quad \tan\theta = \frac{y}{x}$$
- **চতুর্ভাগ ভিত্তিক মুখ্য আর্গুমেন্ট (আদর্শ সীমা $-\pi < \theta \le \pi$ বা $0 \le \theta < 2\pi$):**
  - ১ম চতুর্ভাগ ($x > 0, y > 0$): $\theta = \tan^{-1}\left|\frac{y}{x}\right|$
  - ২য় চতুর্ভাগ ($x < 0, y > 0$): $\theta = \pi - \tan^{-1}\left|\frac{y}{x}\right|$
  - ৩য় চতুর্ভাগ ($x < 0, y < 0$): $\theta = -\pi + \tan^{-1}\left|\frac{y}{x}\right|$ (অথবা ধনাত্মক কোণে $\pi + \tan^{-1}\left|\frac{y}{x}\right|$)
  - ৪র্থ চতুর্ভাগ ($x > 0, y < 0$): $\theta = -\tan^{-1}\left|\frac{y}{x}\right|$ (অথবা $2\pi - \tan^{-1}\left|\frac{y}{x}\right|$)
  - উদাহরণ: $(-3\sqrt{3}, -3) \implies r = \sqrt{(-3\sqrt{3})^2 + (-3)^2} = \sqrt{27+9} = 6$। ৩য় চতুর্ভাগ হওয়ায় $\theta = 180^\circ + 30^\circ = 210^\circ$ বা $-150^\circ$। পোলার স্থানাঙ্ক $(6, 210^\circ)$।
- **পোলার সমীকরণ রূপান্তর ও কনিক শনাক্তকরণ:**
  1. $r(1 + \cos\theta) = 2 \implies r + r\cos\theta = 2 \implies r = 2 - x \implies r^2 = (2-x)^2 \implies x^2 + y^2 = 4 - 4x + x^2 \implies \mathbf{y^2 + 4x = 4}$ (পরাবৃত্ত)।
  2. $r\sin^2\theta + \sin\theta - r = 0 \implies \frac{y^2}{r} + \frac{y}{r} - r = 0 \implies y^2 + y = r^2 = x^2 + y^2 \implies \mathbf{x^2 = y}$ (পরাবৃত্ত)।
  3. $r = \sin(\theta - 45^\circ) = \frac{1}{\sqrt{2}}\sin\theta - \frac{1}{\sqrt{2}}\cos\theta \implies \sqrt{2}r^2 = r\sin\theta - r\cos\theta \implies \mathbf{\sqrt{2}(x^2 + y^2) = y - x}$ (বৃত্ত)।
  4. $r^2 \sin 2\theta = 36 \implies r^2(2\sin\theta\cos\theta) = 36 \implies 2(r\cos\theta)(r\sin\theta) = 36 \implies \mathbf{xy = 18}$ (আয়তাকার অধিবৃত্ত বা সমপরাবৃত্ত)।

### ১.২ দূরত্ব, অন্তর্বিভক্তিকরণ ও কেন্দ্রবিন্দুসমূহ
- **দূরত্ব সূত্র:** $d = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$
- **অনুপাতে বিভক্তিকরণ ($m : n$):**
  - অন্তর্বিভক্তকারী বিন্দু: $P = \left(\frac{m x_2 + n x_1}{m + n}, \; \frac{m y_2 + n y_1}{m + n}\right)$
  - বহির্বিভক্তকারী বিন্দু: $Q = \left(\frac{m x_2 - n x_1}{m - n}, \; \frac{m y_2 - n y_1}{m - n}\right)$
  - মধ্যবিন্দু: $M = \left(\frac{x_1 + x_2}{2}, \; \frac{y_1 + y_2}{2}\right)$
  - সমত্রিখণ্ডক বিন্দুদ্বয়: $1 : 2$ এবং $2 : 1$ অনুপাতে অন্তর্বিভক্ত করে।
- **ত্রিভুজের কেন্দ্রবিন্দুসমূহ ও ইউলার রেখা (Euler Line):**
  - **ভরকেন্দ্র (Centroid, $G$):** $G = \left(\frac{x_1 + x_2 + x_3}{3}, \; \frac{y_1 + y_2 + y_3}{3}\right)$ (মধ্যমাগুলোকে $2:1$ অনুপাতে বিভক্ত করে)।
  - **অন্তঃকেন্দ্র (Incenter, $I$):** $I = \left(\frac{a x_1 + b x_2 + c x_3}{a + b + c}, \; \frac{a y_1 + b y_2 + c y_3}{a + b + c}\right)$
  - **ইউলার রেখা আইডেন্টিটি:** যেকোনো বিষমবাহু ত্রিভুজে লম্ববিন্দু ($H$), ভরকেন্দ্র ($G$), এবং পরিকেন্দ্র ($O$) সমরেখ।
    ভরকেন্দ্র $G$, লম্ববিন্দু ও পরিকেন্দ্রের সংযোজক রেখাকে **$2 : 1$** অনুপাতে অন্তর্বিভক্ত করে ($H$ থেকে $G = 2$, $G$ থেকে $O = 1$):
    $$G = \frac{H + 2O}{3} \iff H = 3G - 2O \iff O = \frac{3G - H}{2}$$
  - **সামান্তরিকের ৪র্থ শীর্ষ নির্ণয়ের সুপার শর্টকাট:**
    কর্ণদ্বয়ের মধ্যবিন্দু একই হওয়ায়: $A + C = B + D \implies \mathbf{D = A + C - B}$
    $D_x = x_A + x_C - x_B, \quad D_y = y_A + y_C - y_B$

### ১.৩ সরলরেখার বিভিন্ন সমীকরণ আকার ও অক্ষের ছেদাংশ
| সমীকরণের রূপ | সাধারণ আকার | বৈশিষ্ট্য ও তাৎপর্য |
|---|---|---|
| **ঢাল-ছেদক আকার** | $y = mx + c$ | $m$ = ঢাল ($\tan\theta$), $c$ = $y$-অক্ষের ছেদাংশ |
| **বিন্দু-ঢাল আকার** | $y - y_1 = m(x - x_1)$ | $(x_1, y_1)$ বিন্দুগামী এবং $m$ ঢালবিশিষ্ট |
| **দ্বি-বিন্দু আকার** | $\frac{y - y_1}{y_1 - y_2} = \frac{x - x_1}{x_1 - x_2}$ | $(x_1, y_1)$ ও $(x_2, y_2)$ সংযোজক সরলরেখা |
| **ছেদক আকার** | $\frac{x}{a} + \frac{y}{b} = 1$ | $x$-অক্ষের ছেদাংশ $a$, $y$-অক্ষের ছেদাংশ $b$; অক্ষদ্বয়ের সাথে গঠিত ত্রিভুজের ক্ষেত্রফল $= \frac{1}{2}|ab|$ |
| **অভিলম্ব / লম্ব আকার** | $x\cos\alpha + y\sin\alpha = p$ | মূলবিন্দু থেকে লম্ব দূরত্ব $p$ ($p > 0$) এবং লম্বের নতি কোণ $\alpha$ |
| **প্যারামেট্রিক / দূরবর্তী আকার** | $\frac{x - x_1}{\cos\theta} = \frac{y - y_1}{\sin\theta} = \pm r$ | $(x_1, y_1)$ হতে রেখা বরাবর $r$ দূরবর্তী বিন্দুর স্থানাঙ্ক $(x_1 \pm r\cos\theta, y_1 \pm r\sin\theta)$ |

- **ঢাল ($m$) নির্ণয়ের সতর্কতা:**
  - $ax + by + c = 0$ রেখার ঢাল $m = -\frac{\text{x-এর সহগ}}{\text{y-এর সহগ}} = -\frac{a}{b}$।
  - $x$-অক্ষের ধনাত্মক দিকের সাথে কোণ $\theta$ হলে $m = \tan\theta$।
  - $y$-অক্ষের ধনাত্মক দিকের সাথে ঘড়ির কাঁটার দিকে কোণ হলে ঢাল ঋণাত্মক হতে পারে।

### ১.৪ মধ্যবর্তী কোণ, সমান্তরাল ও লম্ব রেখা
- **রেখাদ্বয়ের মধ্যবর্তী কোণ:**
  $$\tan\theta = \pm \frac{m_1 - m_2}{1 + m_1 m_2}$$
  - সূক্ষ্মকোণের জন্য ধনাত্মক মান ($+$) এবং স্থূলকোণের জন্য ঋণাত্মক মান ($-$) গৃহীত হয়।
- **সমান্তরাল রেখার শর্ত:** $m_1 = m_2 \iff \frac{a_1}{a_2} = \frac{b_1}{b_2}$।
  - $ax + by + c = 0$-এর সমান্তরাল রেখা: $ax + by + k = 0$।
  - $(x_1, y_1)$ বিন্দুগামী হলে সরাসরি: $\mathbf{a(x - x_1) + b(y - y_1) = 0}$।
- **লম্ব রেখার শর্ত:** $m_1 m_2 = -1 \iff a_1 a_2 + b_1 b_2 = 0$।
  - $ax + by + c = 0$-এর লম্ব রেখা: $bx - ay + k = 0$।
  - $(x_1, y_1)$ বিন্দুগামী হলে সরাসরি: $\mathbf{b(x - x_1) - a(y - y_1) = 0}$।

### ১.৫ দূরত্ব ও কোণের সমদ্বিখণ্ডক
- **বিন্দু হতে রেখার লম্ব দূরত্ব:**
  $$d = \frac{|a x_1 + b y_1 + c|}{\sqrt{a^2 + b^2}}$$
- **দুটি সমান্তরাল রেখার মধ্যবর্তী লম্ব দূরত্ব:**
  $ax + by + c_1 = 0$ এবং $ax + by + c_2 = 0$ হলে:
  $$d = \frac{|c_1 - c_2|}{\sqrt{a^2 + b^2}}$$
  *(সতর্কতা: দূরত্বের সূত্রে বসানোর পূর্বে উভয় সমীকরণে $x$ ও $y$-এর সহগ সমান করে নিতে হবে)*।
- **কোণের সমদ্বিখণ্ডক সমীকরণ:**
  $$\frac{a_1 x + b_1 y + c_1}{\sqrt{a_1^2 + b_1^2}} = \pm \frac{a_2 x + b_2 y + c_2}{\sqrt{a_2^2 + b_2^2}}$$
  - **সূক্ষ্মকোণ ও স্থূলকোণ সমদ্বিখণ্ডক শনাক্তকরণ অ্যালগরিদম:**
    1. প্রথমে উভয় সমীকরণের ধ্রুবক পদকে ধনাত্মক ($c_1 > 0, c_2 > 0$) বানাও।
    2. $a_1 a_2 + b_1 b_2$-এর চিহ্ন পরীক্ষা করো:
       - যদি $a_1 a_2 + b_1 b_2 > 0$ হয় $\implies (+)$ চিহ্ন দিলে **স্থূলকোণের** সমদ্বিখণ্ডক, $(-)$ চিহ্ন দিলে **সূক্ষ্মকোণের** সমদ্বিখণ্ডক।
       - যদি $a_1 a_2 + b_1 b_2 < 0$ হয় $\implies (+)$ চিহ্ন দিলে **সূক্ষ্মকোণের** সমদ্বিখণ্ডক, $(-)$ চিহ্ন দিলে **স্থূলকোণের** সমদ্বিখণ্ডক।
    3. মূলবিন্দু ধারণকারী সমদ্বিখণ্ডক: সর্বদা $(+)$ চিহ্নযুক্ত সমীকরণ।

### ১.৬ কনিক ও সরলরেখার স্পর্শক শর্তাবলী (MANDATORY ADVANCED)
একটি সরলরেখা $y = mx + c$ বিভিন্ন কনিককে স্পর্শ করার স্ট্যান্ডার্ড শর্তাবলি এডমিশনের শীর্ষ র‍্যাংক নিশ্চিত করে:

| কনিক | প্রমিত সমীকরণ | $y = mx + c$ স্পর্শক হওয়ার শর্ত | স্পর্শবিন্দুর স্থানাঙ্ক |
|---|---|---|---|
| **পরাবৃত্ত (Parabola)** | $y^2 = 4ax$ | **$c = \frac{a}{m}$** | $\left(\frac{a}{m^2}, \; \frac{2a}{m}\right)$ |
| **পরাবৃত্ত (Parabola)** | $x^2 = 4ay$ | **$c = -a m^2$** | $\left(2am, \; am^2\right)$ |
| **বৃত্ত (Circle)** | $x^2 + y^2 = r^2$ | **$c^2 = r^2(1 + m^2) \implies c = \pm r\sqrt{1 + m^2}$** | $\left(\mp \frac{mr}{\sqrt{1+m^2}}, \; \pm \frac{r}{\sqrt{1+m^2}}\right)$ |
| **উপবৃত্ত (Ellipse)** | $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ | **$c^2 = a^2 m^2 + b^2 \implies c = \pm \sqrt{a^2 m^2 + b^2}$** | $\left(\mp \frac{a^2 m}{c}, \; \pm \frac{b^2}{c}\right)$ |
| **অধিবৃত্ত (Hyperbola)**| $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ | **$c^2 = a^2 m^2 - b^2 \implies c = \pm \sqrt{a^2 m^2 - b^2}$** | $\left(\mp \frac{a^2 m}{c}, \; \mp \frac{b^2}{c}\right)$ |

> [!TIP]
> **অধিবৃত্তে বাস্তব স্পর্শকের অস্তিত্ব:** অধিবৃত্তের ক্ষেত্রে $a^2 m^2 - b^2 > 0 \implies m^2 > \frac{b^2}{a^2} \implies |m| > \frac{b}{a}$ হতে হবে। যদি $|m| < \frac{b}{a}$ হয়, তবে ঐ ঢালের কোনো বাস্তব স্পর্শক টানা যায় না!

### ১.৭ অধিবৃত্তের অসীমমুখী রেখা ও নিয়ন্ত্রক বৃত্ত (MANDATORY ADVANCED)
- **অধিবৃত্তের অসীমমুখী রেখা (Asymptotes):**
  - অধিবৃত্ত $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$-এর অসীমমুখী রেখাদ্বয় হলো মূলবিন্দুগামী দুটি সরলরেখা যা বক্ররেখাকে অসীমে স্পর্শ করে:
    $$y = \pm \frac{b}{a}x \iff \frac{x}{a} - \frac{y}{b} = 0 \quad \text{ও} \quad \frac{x}{a} + \frac{y}{b} = 0$$
  - **সংযুক্ত সমীকরণ (Joint Equation):**
    $$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 0$$
    *(অধিবৃত্তের সমীকরণের ধ্রুবক পদ $1$-এর স্থলে $0$ বসালেই অসীমমুখীর যুগ্ম সমীকরণ পাওয়া যায়)*।
  - **অসীমমুখীদ্বয়ের মধ্যবর্তী কোণ:** $2\theta = 2\tan^{-1}\left(\frac{b}{a}\right)$।
  - **সমপরাবৃত্ত বা আয়তাকার অধিবৃত্ত ($a = b$):**
    অসীমমুখী রেখাদ্বয় $y = \pm x \implies$ এরা পরস্পর লম্ব ($90^\circ$ কোণে ছেদ করে)।
- **নিয়ন্ত্রক বৃত্ত বা ডিরেক্টর সার্কেল (Director Circle):**
  কোনো কনিকের উপর পরস্পর লম্ব স্পর্শকদ্বয়ের ছেদবিন্দুর সঞ্চারপথকে তার নিয়ন্ত্রক বৃত্ত বলে।
  - **উপবৃত্তের নিয়ন্ত্রক বৃত্ত:** $x^2 + y^2 = a^2 + b^2$ (ব্যাসার্ধ $\sqrt{a^2 + b^2}$)।
  - **অধিবৃত্তের নিয়ন্ত্রক বৃত্ত:** $x^2 + y^2 = a^2 - b^2$ (বাস্তব বৃত্তের জন্য $a > b$ হতে হবে; $a < b$ হলে কাল্পনিক)।
  - **পরাবৃত্তের লম্ব স্পর্শকের সঞ্চারপথ:** পরাবৃত্ত $y^2 = 4ax$-এর যেকোনো দুটি লম্ব স্পর্শকের ছেদবিন্দু সর্বদা তার **নিয়ামক রেখার (Directrix)** উপর অবস্থান করে ($x = -a$)।

### ১.৮ প্যারামেট্রিক স্থানাঙ্ক রূপান্তর (MANDATORY ADVANCED)
- বিভিন্ন বক্ররেখার স্ট্যান্ডার্ড প্যারামেট্রিক রূপ:
  - বৃত্ত $x^2 + y^2 = r^2 \implies x = r\cos\theta, \; y = r\sin\theta$ (প্যারামিটার $\theta$)
  - উপবৃত্ত $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \implies x = a\cos\theta, \; y = b\sin\theta$
  - অধিবৃত্ত $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1 \implies x = a\sec\theta, \; y = b\tan\theta$
  - পরাবৃত্ত $y^2 = 4ax \implies x = a t^2, \; y = 2at$ (প্যারামিটার $t$)
  - সরলরেখা $\frac{x - x_1}{\cos\theta} = \frac{y - y_1}{\sin\theta} = r \implies x = x_1 + r\cos\theta, \; y = y_1 + r\sin\theta$

### ১.৯ যোগাশ্রয়ী প্রোগ্রাম ও পরমমান অসমতা (MANDATORY ADVANCED)
- **পরমমান অসমতার কেন্দ্র-ব্যাসার্ধ সূত্র:**
  $$|x - m| < r \iff m - r < x < m + r$$
  যেখানে কেন্দ্র $m = \frac{a + b}{2}$ এবং ব্যাসার্ধ $r = \frac{b - a}{2}$।
  - উদাহরণ: $-2 < x < 8 \implies m = \frac{-2+8}{2} = 3, \; r = \frac{8 - (-2)}{2} = 5 \implies |x - 3| < 5$।
- **ভগ্নাংশীয় পরমমান অসমতার ডোমেন ট্র্যাপ:**
  $$\frac{1}{|x - a|} \ge k \implies |x - a| \le \frac{1}{k} \quad (\text{কিন্তু } x \neq a)$$
  - সমাধান ব্যবধি: $\left[a - \frac{1}{k}, \; a + \frac{1}{k}\right] \setminus \{a\}$ (হর শূন্য হতে পারে না!)।
- **যোগাশ্রয়ী প্রোগ্রাম (Linear Programming - LPP):**
  - **সীমাবদ্ধ এলাকা (Feasible Region):** প্রদত্ত অসমতাসমূহ দ্বারা আবদ্ধ উত্তল বহুভুজ এলাকা।
  - **চরম মান উপপাদ্য (Fundamental Theorem of LPP):** উদ্দেশ্য অপেক্ষক $Z = ax + by$-এর সর্বোচ্চ বা সর্বনিম্ন মান সর্বদা সীমাবদ্ধ এলাকার **কৌণিক বিন্দুগুলোতে (Corner/Extreme Points)** অর্জিত হয়।

## ৪. ⚡ ১৫টি হাই-প্রবাবিলিটি প্রেডিক্টিভ প্রশ্ন ও টুইস্টেড ভ্যারিয়েশনস

### Q01. উপবৃত্তের স্পর্শক শর্ত ও ধ্রুবক নির্ণয় [DU '24 Expected]
**প্রশ্ন:** $y = 2x + k$ সরলরেখাটি $\frac{x^2}{4} + \frac{y^2}{9} = 1$ উপবৃত্তকে স্পর্শ করলে ধ্রুবক $k$-এর মান কত?  
(a) $\pm 5$  
(b) $\pm \sqrt{17}$  
(c) $\pm 7$  
(d) $\pm \sqrt{41}$  

- **সঠিক উত্তর:** (a) $\pm 5$
- **ইঞ্জিনিয়ারিং টু ভার্সিটি ট্রান্সফার:** সাধারণ উপবৃত্তে শীর্ষ ও উৎকেন্দ্রিকতা চায়; কিন্তু ঢাবির সাম্প্রতিক ট্রেন্ডে স্পর্শক শর্তাবলী সরাসরি অন্তর্ভুক্ত।
- **ফরেনসিক ট্র্যাপ ব্রেকডাউন:**
  - অপশন (b) $\pm\sqrt{17}$: ছাত্ররা $a^2 + b^2$ যোগ করে ভুল করে ($4 + 9 = 13$, অথবা ঢাল না গুণ করে)।

- **৩০-সেকেন্ড মেন্টাল ম্যাথ:**
  স্পর্শকের শর্ত: $c^2 = a^2 m^2 + b^2$
  এখানে $a^2 = 4, b^2 = 9, m = 2$।
  $k^2 = (4 \times 2^2) + 9 = (4 \times 4) + 9 = 16 + 9 = 25 \implies k = \pm 5$। কোনো খাতা-কলম লাগে না!

### Q02. পরাবৃত্তের স্পর্শকের স্পর্শবিন্দু নির্ণয় [CKRUET Preliminary]

### Q05. ভগ্নাংশীয় পরমমান অসমতার ডোমেন বর্জন [DU '23 Repeat Pattern]

(c) $\left[\frac{7}{10}, \frac{8}{10}\right]$

### Q06. অধিবৃত্তের অসীমমুখী রেখাদ্বয়ের মধ্যবর্তী কোণ [BUET/CKRUET]

(b) $60^\circ$  
(c) $45^\circ$  
(d) $90^\circ$

(b) $7\pi$  
(c) $144\pi$

- **সঠিক উত্তর:** (a) $25\pi$
- **৩০-সেকেন্ড মেন্টাল ম্যাথ:**
  প্রমিত আকার: $\frac{x^2}{16} + \frac{y^2}{9} = 1 \implies a^2 = 16, b^2 = 9$।

  $x^2 + y^2 = a^2 + b^2 = 16 + 9 = 25$।
  বৃত্তের ব্যাসার্ধ $R = 5$ একক। ক্ষেত্রফল $= \pi R^2 = 25\pi$ বর্গ একক।

(b) $21x + 77y + 2 = 0$  
(c) $21x - 77y - 2 = 0$  
(d) $99x + 27y - 28 = 0$

## ৫. ইঞ্জিনিয়ারিং টু ঢাবি লিখিত ট্রান্সফার — সেরা ৫টি কনসেপচুয়াল প্রমাণ

### Written 01: উপবৃত্তের লম্ব স্পর্শকের ছেদবিন্দুর সঞ্চারপথ (নিয়ন্ত্রক বৃত্ত) প্রমাণ
**সমস্যা:** প্রমাণ করো যে $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ উপবৃত্তের পরস্পর লম্ব স্পর্শকদ্বয়ের ছেদবিন্দুর সঞ্চারপথ একটি বৃত্ত যার সমীকরণ $x^2 + y^2 = a^2 + b^2$।
**সমাধান:**
উপবৃত্তের যেকোনো স্পর্শকের সমীকরণ: $y = mx + \sqrt{a^2 m^2 + b^2}$
ছেদবিন্দু $(h, k)$ হলে:
$k - mh = \sqrt{a^2 m^2 + b^2}$
উভয়পাশে বর্গ করে:
$(k - mh)^2 = a^2 m^2 + b^2 \implies k^2 - 2mhk + m^2 h^2 = a^2 m^2 + b^2$
$m$-এর দ্বিঘাত সমীকরণ আকারে সাজিয়ে:
$(h^2 - a^2)m^2 - 2hkm + (k^2 - b^2) = 0$
যেহেতু স্পর্শকদ্বয় পরস্পর লম্ব, তাদের ঢালদ্বয়ের গুণফল $m_1 m_2 = -1$।
মূলদ্বয়ের গুণফল: $\frac{k^2 - b^2}{h^2 - a^2} = -1$
$k^2 - b^2 = -(h^2 - a^2) = -h^2 + a^2$
$h^2 + k^2 = a^2 + b^2$
অতএব সঞ্চারপথের সমীকরণ: $x^2 + y^2 = a^2 + b^2$ [প্রমাণিত]।

### Written 02: সামান্তরিকের ক্ষেত্রফল ও কর্ণ সূত্রের ভেক্টর-জ্যামিতিক প্রমাণ
**সমস্যা:** দেখাও যে $x\cos\alpha + y\sin\alpha = p$ সরলরেখাটি অক্ষদ্বয়কে $A$ ও $B$ বিন্দুতে ছেদ করলে $AB$-এর মধ্যবিন্দুর সঞ্চারপথের সমীকরণ $\frac{1}{x^2} + \frac{1}{y^2} = \frac{4}{p^2}$।
**সমাধান:**
সমীকরণটিকে ছেদক আকারে প্রকাশ করে:
$\frac{x}{p/\cos\alpha} + \frac{y}{p/\sin\alpha} = 1$
অক্ষদ্বয়ের ছেদবিন্দু: $A\left(\frac{p}{\cos\alpha}, 0\right)$ এবং $B\left(0, \frac{p}{\sin\alpha}\right)$।
ধরি $AB$-এর মধ্যবিন্দু $(h, k)$।
$h = \frac{p}{2\cos\alpha} \implies \cos\alpha = \frac{p}{2h}$
$k = \frac{p}{2\sin\alpha} \implies \sin\alpha = \frac{p}{2k}$
আমরা জানি $\cos^2\alpha + \sin^2\alpha = 1$:
$\left(\frac{p}{2h}\right)^2 + \left(\frac{p}{2k}\right)^2 = 1 \implies \frac{p^2}{4h^2} + \frac{p^2}{4k^2} = 1$
উভয়পাশে $p^2/4$ দ্বারা ভাগ করে:
$\frac{1}{h^2} + \frac{1}{k^2} = \frac{4}{p^2}$
অতএব সঞ্চারপথ: $\frac{1}{x^2} + \frac{1}{y^2} = \frac{4}{p^2}$ [প্রমাণিত]।

### Written 03: কোণের সমদ্বিখণ্ডকের প্রকৃতি ও মূলবিন্দু ধারণের শর্ত
**সমস্যা:** $4x - 3y + 1 = 0$ এবং $12x - 5y + 7 = 0$ রেখাদ্বয়ের অন্তর্ভুক্ত কোণের কোন সমদ্বিখণ্ডকটি মূলবিন্দু ধারণ করে এবং এটি সূক্ষ্মকোণ না স্থূলকোণের সমদ্বিখণ্ডক?
**সমাধান:**
উভয় সমীকরণে ধ্রুবক পদ $c_1 = 1 > 0$ এবং $c_2 = 7 > 0$ (উভয়ই ধনাত্মক)।
মূলবিন্দু ধারণকারী সমদ্বিখণ্ডকটি সর্বদা $(+)$ চিহ্নবিশিষ্ট হবে:
$\frac{4x - 3y + 1}{\sqrt{4^2 + (-3)^2}} = +\frac{12x - 5y + 7}{\sqrt{12^2 + (-5)^2}}$
$\frac{4x - 3y + 1}{5} = \frac{12x - 5y + 7}{13}$
$13(4x - 3y + 1) = 5(12x - 5y + 7) \implies 52x - 39y + 13 = 60x - 25y + 35$
$8x + 14y + 22 = 0 \implies 4x + 7y + 11 = 0$ (মূলবিন্দু ধারণকারী)।
প্রকৃতি নির্ণয়:
$a_1 a_2 + b_1 b_2 = (4)(12) + (-3)(-5) = 48 + 15 = 63 > 0$।
যেহেতু $a_1 a_2 + b_1 b_2 > 0$, তাই $(+)$ চিহ্নটি **স্থূলকোণের** সমদ্বিখণ্ডক।
সুতরাং মূলবিন্দু ধারণকারী সমদ্বিখণ্ডকটি একটি **স্থূলকোণের সমদ্বিখণ্ডক**।

### Written 04: অধিবৃত্তের অসীমমুখী রেখাদ্বয়ের অন্তর্ভুক্ত কোণ প্রমাণ
**সমস্যা:** দেখাও যে $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ অধিবৃত্তের উৎকেন্দ্রিকতা $e$ হলে তার অসীমমুখী রেখাদ্বয়ের মধ্যবর্তী কোণ $2\sec^{-1}(e)$।
**সমাধান:**
অধিবৃত্তের অসীমমুখীর সমীকরণ: $y = \pm \frac{b}{a}x$।
একটি অসীমমুখী $x$-অক্ষের সাথে $\theta$ কোণ তৈরি করলে $\tan\theta = \frac{b}{a}$।
আমরা জানি $e^2 = 1 + \frac{b^2}{a^2} = 1 + \tan^2\theta = \sec^2\theta$।
$\sec\theta = e \implies \theta = \sec^{-1}(e)$।
অসীমমুখী রেখাদ্বয় প্রতিসাম্যভাবে $x$-অক্ষের উভয় পাশে অবস্থিত হওয়ায় এদের মধ্যবর্তী মোট কোণ:
$2\theta = 2\sec^{-1}(e)$ [প্রমাণিত]।

### Written 05: যোগাশ্রয়ী প্রোগ্রামে অসমতা এলাকার চরমমান
**সমস্যা:** লেখচিত্রের সাহায্যে নিচের শর্তাধীনে $Z = 4x + 3y$-এর সর্বোচ্চ মান নির্ণয় করো:
$x + 2y \le 10, \quad 3x + y \le 15, \quad x \ge 0, \quad y \ge 0$
**সমাধান:**
সীমাবদ্ধ রেখা ১: $x + 2y = 10 \implies \frac{x}{10} + \frac{y}{5} = 1$ (ছেদবিন্দু $(10,0), (0,5)$)।
সীমাবদ্ধ রেখা ২: $3x + y = 15 \implies \frac{x}{5} + \frac{y}{15} = 1$ (ছেদবিন্দু $(5,0), (0,15)$)।
রেখাদ্বয়ের ছেদবিন্দু:
২ নং কে ২ দিয়ে গুণ করে ১ বিয়োগ: $6x + 2y - (x + 2y) = 30 - 10 \implies 5x = 20 \implies x = 4$।
$y = 15 - 3(4) = 3$। ছেদবিন্দু $B(4, 3)$।
সীমাবদ্ধ এলাকার কৌণিক বিন্দুসমূহ:
$O(0, 0), \quad A(5, 0), \quad B(4, 3), \quad C(0, 5)$
উদ্দেশ্য অপেক্ষকে মান বসিয়ে:
$Z(O) = 4(0) + 3(0) = 0$
$Z(A) = 4(5) + 3(0) = 20$
$Z(B) = 4(4) + 3(3) = 16 + 9 = 25$
$Z(C) = 4(0) + 3(5) = 15$
অতএব $(4, 3)$ বিন্দুতে $Z$-এর সর্বোচ্চ মান $= 25$।

## ৬. হাই-রিস্ক ট্র্যাপ ব্রেকার ও স্টুডেন্ট ভুল বিশ্লেষণ

| ট্র্যাপ কোড | সাধারণ ছাত্র ভুল (Negative Mark Trap) | বৈজ্ঞানিক সত্য ও সমাধান (The Fix) |
|---|---|---|
| **TRAP-M01** | ঢাল নির্ণয়ে $-a/b$ এর বদলে $a/b$ লিখে ফেলা | সব পদ একপাশে এনে ($ax+by+c=0$) ঢাল $m = -\frac{\text{x-এর সহগ}}{\text{y-এর সহগ}} = -a/b$। |
| **TRAP-M02** | সমান্তরাল রেখার দূরত্বে সহগ সমান করতে ভুলে যাওয়া | $3x-4y=2$ ও $6x-8y=9$ থাকলে আগে দ্বিতীয়টিকে ২ দিয়ে ভাগ করে সহগ ৩ ও ৪ বানাতে হবে। |
| **TRAP-M03** | ৩য় চতুর্ভাগের পোলার কোণ ঋণাত্মক না ধনাত্মক তা না দেখা | অপশনে $210^\circ$ বা $-150^\circ$ উভয়ই থাকতে পারে; মুখ্য কোণ সীমা $(-\pi, \pi]$ হলে $-150^\circ$। |
| **TRAP-M04** | $1/|x-a| \ge k$ অসমতায় $x=a$ বাদ না দেওয়া | হরে $|x-a|$ থাকায় $x=a$ বিন্দুতে অসংজ্ঞায়িত; সমাধান ব্যবধি থেকে অবশ্যই $\{a\}$ বাদ দিতে হবে। |
| **TRAP-M05** | উপবৃত্তে $a > b$ ও $b > a$ না দেখে উপকেন্দ্রিক লম্ব লেখা | $b > a$ হলে উপকেন্দ্রিক লম্ব $\frac{2a^2}{b}$ এবং স্পর্শক শর্ত $c^2 = a^2 m^2 + b^2$ একই থাকে। |
| **TRAP-M06** | পরাবৃত্তের স্পর্শকে $c = a/m$ এর বদলে $am$ লেখা | $y^2 = 4ax$-এর জন্য $c = a/m$; আর $x^2 = 4ay$-এর জন্য $c = -am^2$। |
| **TRAP-M07** | ইউলার রেখায় $H, G, O$-এর অনুপাত $1:2$ ভাবা | $H$ থেকে $G$-এর দূরত্ব দ্বিগুণ ($HG : GO = 2 : 1$); অর্থাৎ $G = (H+2O)/3$। |
| **TRAP-M08** | সামান্তরিকের ৪র্থ শীর্ষ নির্ণয়ে $B$ যোগ করে ফেলা | সূত্র হলো $D = A + C - B$; কর্ণদ্বয়ের বিপরীত শীর্ষ যোগ করে অপরটি বিয়োগ। |
| **TRAP-M09** | মধ্যবর্তী সূক্ষ্মকোণে মাইনাস চিহ্ন অগ্রাহ্য করা | $\tan\theta$-এর মান ধনাত্মক হলে সূক্ষ্মকোণ, ঋণাত্মক হলে স্থূলকোণ। |
| **TRAP-M10** | কোণের সমদ্বিখণ্ডকে $c_1, c_2$ ধনাত্মক না বানিয়েই সূত্র প্রয়োগ | আগে ধ্রুবক পদ পজিটিভ করতে হবে, অন্যথায় স্থূলকোণ ও সূক্ষ্মকোণ সম্পূর্ণ ওলটপালট হয়ে যাবে। |
| **TRAP-M11** | সমপরাবৃত্তের অসীমমুখীর মধ্যবর্তী কোণ ভুলে যাওয়া | সমপরাবৃত্তে $a=b$, তাই অসীমমুখীদ্বয় সর্বদা পরস্পর লম্ব ($90^\circ$)। |
| **TRAP-M12** | যোগাশ্রয়ী প্রোগ্রামে অবাস্তব বিন্দু যাচাই না করা | $x \ge 0, y \ge 0$ শর্তে প্রথম চতুর্ভাগের বাইরের কোনো ছেদবিন্দু গ্রহণযোগ্য নয়। |

## ৭. আনলিমিটেড অ্যাক্টিভ-রিকল রিপোজিটরি (৪৫টি হাই-ইল্ড ফ্ল্যাশকার্ড)

- **FC-01:** কার্তেসীয় $(x, y)$ হতে পোলার $(r, \theta)$ রূপান্তরের সূত্র কী? $\to$ $r = \sqrt{x^2 + y^2}, \; \theta = \tan^{-1}(y/x)$।
- **FC-02:** ৩য় চতুর্ভাগে অবস্থিত বিন্দুর মুখ্য আর্গুমেন্টের সীমা কত? $\to$ $-\pi < \theta < -\pi/2$ (অথবা $\theta = -\pi + \alpha$)।
- **FC-03:** $r(1 + \cos\theta) = 2$ সমীকরণটি কোন বক্ররেখা নির্দেশ করে? $\to$ পরাবৃত্ত ($y^2 + 4x = 4$)।
- **FC-04:** $r^2 \sin 2\theta = 36$ সমীকরণটি কোন বক্ররেখা নির্দেশ করে? $\to$ আয়তাকার অধিবৃত্ত বা সমপরাবৃত্ত ($xy = 18$)।
- **FC-05:** সামান্তরিকের তিনটি শীর্ষ $A, B, C$ হলে ৪র্থ শীর্ষ $D$-এর স্থানাঙ্ক কী? $\to$ $D = A + C - B$।
- **FC-06:** ত্রিভুজের ভরকেন্দ্র মধ্যমাকে কী অনুপাতে বিভক্ত করে? $\to$ শীর্ষ হতে ভূমির দিকে $2 : 1$ অনুপাতে।
- **FC-07:** ইউলার রেখায় লম্ববিন্দু ($H$), ভরকেন্দ্র ($G$) ও পরিকেন্দ্র ($O$)-এর অনুপাত কী? $\to$ $HG : GO = 2 : 1$।
- **FC-08:** ইউলার রেখা সূত্রে ভরকেন্দ্র $G$-এর সমীকরণ কী? $\to$ $G = \frac{H + 2O}{3}$।
- **FC-09:** ইউলার রেখা সূত্রে লম্ববিন্দু $H$-এর সমীকরণ কী? $\to$ $H = 3G - 2O$।
- **FC-10:** $ax + by + c = 0$ সরলরেখার ঢাল কত? $\to$ $-a/b$।
- **FC-11:** দুটি সরলরেখা পরস্পর লম্ব হওয়ার শর্ত কী? $\to$ $m_1 m_2 = -1$ অথবা $a_1 a_2 + b_1 b_2 = 0$।
- **FC-12:** দুটি সরলরেখা সমান্তরাল হওয়ার শর্ত কী? $\to$ $m_1 = m_2$ অথবা $\frac{a_1}{a_2} = \frac{b_1}{b_2}$।
- **FC-13:** $\frac{x}{a} + \frac{y}{b} = 1$ সরলরেখা ও অক্ষদ্বয় দ্বারা গঠিত ত্রিভুজের ক্ষেত্রফল কত? $\to$ $\frac{1}{2}|ab|$।
- **FC-14:** সমান্তরাল রেখাদ্বয়ের মধ্যবর্তী লম্ব দূরত্বের সূত্র কী? $\to$ $d = \frac{|c_1 - c_2|}{\sqrt{a^2 + b^2}}$ (সহগ সমান করার পর)।
- **FC-15:** বিন্দু $(x_1, y_1)$ হতে $ax + by + c = 0$-এর লম্ব দূরত্ব কত? $\to$ $d = \frac{|a x_1 + b y_1 + c|}{\sqrt{a^2 + b^2}}$।
- **FC-16:** $y = mx + c$ রেখাটি $y^2 = 4ax$ পরাবৃত্তের স্পর্শক হওয়ার শর্ত কী? $\to$ $c = \frac{a}{m}$।
- **FC-17:** $y^2 = 4ax$ পরাবৃত্তে $y = mx + a/m$ স্পর্শকের স্পর্শবিন্দু কোনটি? $\to$ $\left(\frac{a}{m^2}, \frac{2a}{m}\right)$।
- **FC-18:** $y = mx + c$ রেখাটি $x^2 = 4ay$ পরাবৃত্তের স্পর্শক হওয়ার শর্ত কী? $\to$ $c = -a m^2$।
- **FC-19:** $y = mx + c$ রেখাটি $x^2 + y^2 = r^2$ বৃত্তের স্পর্শক হওয়ার শর্ত কী? $\to$ $c^2 = r^2(1 + m^2)$।
- **FC-20:** $y = mx + c$ রেখাটি $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ উপবৃত্তের স্পর্শক হওয়ার শর্ত কী? $\to$ $c^2 = a^2 m^2 + b^2$।
- **FC-21:** $y = mx + c$ রেখাটি $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ অধিবৃত্তের স্পর্শক হওয়ার শর্ত কী? $\to$ $c^2 = a^2 m^2 - b^2$।
- **FC-22:** অধিবৃত্তে বাস্তব স্পর্শক পাওয়ার জন্য ঢালের সীমা কী? $\to$ $m^2 > b^2/a^2 \iff |m| > b/a$।
- **FC-23:** $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ অধিবৃত্তের অসীমমুখী রেখাদ্বয়ের সমীকরণ কী? $\to$ $y = \pm \frac{b}{a}x$ বা $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 0$।
- **FC-24:** সমপরাবৃত্তের ($a=b$) অসীমমুখীদ্বয়ের মধ্যবর্তী কোণ কত? $\to$ $90^\circ$ (পরস্পর লম্ব)।
- **FC-25:** উপবৃত্তের নিয়ন্ত্রক বৃত্তের (Director Circle) সমীকরণ কী? $\to$ $x^2 + y^2 = a^2 + b^2$।
- **FC-26:** অধিবৃত্তের নিয়ন্ত্রক বৃত্তের সমীকরণ কী? $\to$ $x^2 + y^2 = a^2 - b^2$ ($a > b$ এর জন্য)।
- **FC-27:** পরাবৃত্তের লম্ব স্পর্শকদ্বয়ের ছেদবিন্দুর সঞ্চারপথ কোনটি? $\to$ পরাবৃত্তের নিয়ামক রেখা বা Directrix ($x = -a$)।
- **FC-28:** উপবৃত্তের প্যারামেট্রিক স্থানাঙ্ক কী? $\to$ $(a\cos\theta, b\sin\theta)$।
- **FC-29:** অধিবৃত্তের প্যারামেট্রিক স্থানাঙ্ক কী? $\to$ $(a\sec\theta, b\tan\theta)$।
- **FC-30:** পরাবৃত্তের প্যারামেট্রিক স্থানাঙ্ক কী? $\to$ $(at^2, 2at)$।
- **FC-31:** সরলরেখার দূরবর্তী প্যারামেট্রিক আকার কোনটি? $\to$ $\frac{x - x_1}{\cos\theta} = \frac{y - y_1}{\sin\theta} = \pm r$।
- **FC-32:** পরমমান অসমতা $|x - m| < r$-এর কেন্দ্র ও ব্যাসার্ধ কী? $\to$ কেন্দ্র $m = (a+b)/2$, ব্যাসার্ধ $r = (b-a)/2$।
- **FC-33:** $\frac{1}{|x - a|} \ge k$ অসমতার সমাধানে কোন বিন্দুটি বাদ দিতে হয়? $\to$ $x = a$ বিন্দুটি (যেহেতু হর শূন্য হয়)।
- **FC-34:** কোণের সমদ্বিখণ্ডকে মূলবিন্দু ধারণকারী সমীকরণ কোনটি? $\to$ ধ্রুবক পদ পজিটিভ করার পর $(+)$ চিহ্নযুক্ত সমীকরণ।
- **FC-35:** $a_1 a_2 + b_1 b_2 > 0$ হলে $(+)$ চিহ্ন কোন কোণের সমদ্বিখণ্ডক নির্দেশ করে? $\to$ স্থূলকোণের সমদ্বিখণ্ডক।
- **FC-36:** $a_1 a_2 + b_1 b_2 > 0$ হলে $(-)$ চিহ্ন কোন কোণের সমদ্বিখণ্ডক নির্দেশ করে? $\to$ সূক্ষ্মকোণের সমদ্বিখণ্ডক।
- **FC-37:** তিনটি বিন্দু সমরেখ হওয়ার প্রধান দুটি শর্ত কী? $\to$ বিন্দুত্রয় দ্বারা গঠিত ত্রিভুজের ক্ষেত্রফল শূন্য অথবা যেকোনো দুটি বিন্দুর ঢাল সমান।
- **FC-38:** অক্ষদ্বয় হতে সমান কিন্তু বিপরীত চিহ্নযুক্ত অংশ ছেদকারী রেখার ঢাল কত? $\to$ $m = +1$ ($x/a + y/(-a) = 1 \implies y = x - a$)।
- **FC-39:** অক্ষদ্বয় হতে সমান ও একই চিহ্নযুক্ত অংশ ছেদকারী রেখার ঢাল কত? $\to$ $m = -1$ ($x/a + y/a = 1 \implies y = -x + a$)।
- **FC-40:** মূলবিন্দুগামী রেখার সমীকরণ কী? $\to$ $y = mx$ (ধ্রুবক পদ $c = 0$)।
- **FC-41:** যোগাশ্রয়ী প্রোগ্রামে উদ্দেশ্য অপেক্ষকের চরম মান কোথায় অর্জিত হয়? $\to$ সীমাবদ্ধ এলাকার কৌণিক বা শীর্ষবিন্দুগুলোতে (Corner Points)।
- **FC-42:** যোগাশ্রয়ী প্রোগ্রামের সীমাবদ্ধ এলাকাটি সর্বদা কেমন বহুভুজ হয়? $\to$ উত্তল বহুভুজ (Convex Polygon)।
- **FC-43:** $x$-অক্ষের সমান্তরাল রেখার সমীকরণ কী? $\to$ $y = b$ (ঢাল শূন্য)।
- **FC-44:** $y$-অক্ষের সমান্তরাল রেখার সমীকরণ কী? $\to$ $x = a$ (ঢাল অসংজ্ঞায়িত)।
- **FC-45:** দুটি বিন্দু $(x_1, y_1)$ ও $(x_2, y_2)$-এর সংযোজক রেখাকে $x$-অক্ষ কী অনুপাতে বিভক্ত করে? $\to$ $-y_1 : y_2$ অনুপাতে ($y$-স্থানাঙ্কের বিপরীত অনুপাতে)।

## ৮. লাস্ট নাইট র‍্যাপিড রিভিশন ক্যাপসুল ও ২৫টি হাই-ইল্ড সেলফ-টেস্ট MCQ

### ৮.১ ১-পৃষ্ঠার আল্ট্রা সামারি ফর্মুলা বুস্টার
- **স্থানাঙ্ক ও ইউলার:** $r=\sqrt{x^2+y^2}$; $D = A + C - B$; ইউলার রেখা $HG : GO = 2 : 1 \implies G = \frac{H+2O}{3}$
- **দূরত্ব ও কোণ:** $d = \frac{|ax_1+by_1+c|}{\sqrt{a^2+b^2}}$; সমান্তরাল দূরত্ব $d = \frac{|c_1-c_2|}{\sqrt{a^2+b^2}}$; $\tan\theta = \pm \frac{m_1-m_2}{1+m_1m_2}$
- **স্পর্শক শর্তাবলি:**
  - পরাবৃত্ত $y^2=4ax \to c = a/m$; স্পর্শবিন্দু $(a/m^2, 2a/m)$
  - বৃত্ত $x^2+y^2=r^2 \to c = \pm r\sqrt{1+m^2}$
  - উপবৃত্ত $\frac{x^2}{a^2}+\frac{y^2}{b^2}=1 \to c = \pm \sqrt{a^2 m^2 + b^2}$
  - অধিবৃত্ত $\frac{x^2}{a^2}-\frac{y^2}{b^2}=1 \to c = \pm \sqrt{a^2 m^2 - b^2}$
- **অসীমমুখী ও ডিরেক্টর সার্কেল:** অধিবৃত্তের অসীমমুখী $y = \pm \frac{b}{a}x$; ডিরেক্টর সার্কেল $x^2+y^2=a^2+b^2$ (উপবৃত্ত) ও $x^2+y^2=a^2-b^2$ (অধিবৃত্ত)
- **অসমতা ও LPP:** $|x-m|<r \iff m-r < x < m+r$; $\frac{1}{|x-a|}\ge k \implies x \in [a-1/k, a+1/k] \setminus \{a\}$
