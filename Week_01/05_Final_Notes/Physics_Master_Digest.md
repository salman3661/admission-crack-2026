## ১. ওয়ান-স্টপ মাস্টার হ্যান্ডনোট

### ১.১ স্কেলার ও ভেক্টর রাশি
| ধরন | উদাহরণ |
|---|---|
| **স্কেলার** | দৈর্ঘ্য, ভর, সময়, কাজ, শক্তি, ক্ষমতা, চাপ, তড়িৎ বিভব, তড়িৎ প্রবাহ, দ্রুতি, **স্থিতিশক্তি**, তাপমাত্রা, বলের ভ্রামক **বাদে** সকল ভ্রামক |
| **ভেক্টর** | সরণ, বেগ, ত্বরণ, বল, ভরবেগ, ঘাত, টর্ক, কৌণিক বেগ, কৌণিক ভরবেগ, তড়িৎ ক্ষেত্র |

- বল ও টর্ক ভেক্টর; **টর্ক = r × F**, **কৌণিক ভরবেগ L = r × p**।
- স্কেলার গুণফলের উদাহরণ: কাজ, স্থিতিশক্তি, তড়িৎ প্রবাহ। ভেক্টর গুণফলের উদাহরণ: বেগ v = ω × r, টর্ক।
- [SRC: MEDICAL_UNMESH] **স্কেলার ফাংশনকে ভেক্টরে রূপান্তর করে → গ্র্যাডিয়েন্ট**; **ডাইভারজেন্স ভেক্টর ক্ষেত্রকে স্কেলারে রূপান্তর করে**।

### ১.২ ভেক্টর যোগ-বিয়োগ
- সামান্তরিক সূত্র: **R = √(P² + Q² + 2PQ cosθ)**, দিক: **tanβ = Q sinθ / (P + Q cosθ)**।
- সর্বোচ্চ লব্ধি = P + Q (θ = 0°), সর্বনিম্ন = |P − Q| (θ = 180°)।
- সমান মানের দুই ভেক্টরের লব্ধি = 2P cos(θ/2)।
- দুই ভেক্টর পরস্পর লম্ব হলে R = √(P² + Q²)। যদি লব্ধি (R) একটি ভেক্টর Q-র ওপর লম্ব হয় তবে বড়টি = √(P² + R²) [Varsity: লব্ধি 4 N, ছোটটি 3 N → বড়টি 5 N]।
- **সামান্তরিকের দুই সন্নিহিত বাহু A, B হলে কর্ণ = A + B ও A − B।** উল্টো দিকে, দুই কর্ণ D₁, D₂ জানা থাকলে **বাহু = (D₁ ± D₂)/2**।
  - উদাহরণ: কর্ণ 5î+10ĵ+10k̂ ও î−2ĵ → বাহু (3î+4ĵ+5k̂) ও (2î+6ĵ+5k̂)।

### ১.৩ ভেক্টর বিভাজন ও উপাংশ
- ভেক্টর F, অনুভূমিকের সাথে θ কোণে: **অনুভূমিক = F cosθ, উল্লম্ব = F sinθ**।
- নতিতলে/কোণে টানা বস্তুর ওজন হ্রাস: ধরো 15 N বল 30° কোণে → ওজন হ্রাস = 15 sin30° = **7.5 N**; 25 N ঠেলায় (150° কোণ) ওজন বৃদ্ধি = 25 sin(180°−150°) = **12.5 N**।
- ভেক্টর A-এর B বরাবর উপাংশ: **A_∥ = (A·B / |B|²) B**; লম্ব উপাংশ: **A_⊥ = A − A_∥**।
  - [SRC: ENGG_EXTRA] B = î+2ĵ+2k̂ বরাবর A = −î+ĵ−k̂ → A_∥ = −(1/9)(î+2ĵ+2k̂), A_⊥ = −(1/9)(8î−11ĵ+7k̂)।
- **লম্ব অভিক্ষেপ (projection)** = **A cosθ = A·B / |B|**। উদাহরণ: P = î−ĵ−2k̂, Q = 2î+3ĵ+6k̂ → P_on_Q = (2−3−12)/7 = **−13/7** ([SRC: VARSITY_KA])।
- **দিক কোসাইন:** l = Ax/|A|, m = Ay/|A|, n = Az/|A|; **l² + m² + n² = 1**। উদাহরণ: R = 5î−2ĵ−6k̂ → |R| = √65; x, y, z অক্ষের সাথে কোণ = cos⁻¹(5/√65) = 51.67°, cos⁻¹(−2/√65) = 104.36°, cos⁻¹(−6/√65) = 138.09°।
- অক্ষতলে ভেক্টর: yz-তলে 5î+3ĵ+4k̂-এর দৈর্ঘ্য = √(3²+4²) = 5 (**√25**); xz-তলে √(5²+(−3)²) = √34।
- একক ভেক্টর **â = A/|A|**; −â = বিপরীত দিক। অক্ষ বরাবর 45° কোণে একক ভেক্টরের উপাংশ = **1/√2** করে। **বিপ্রতীপ ভেক্টর** (k̂ বরাবর 5k̂ এর) = (1/5)k̂ = **0.2k̂**।
- **নাল ভেক্টর:** পাদবিন্দু ও শীর্ষবিন্দু একই; দিক নির্দিষ্ট নেই; মান শূন্য।
- সমরেখ/সমান্তরাল ভেক্টর: **A × B = 0**; A = 5î+2ĵ−3k̂, B = 10î+aĵ−6k̂ সমান্তরাল → 5/10 = 2/a → **a = 4**।

### ১.৪ ডট ও ক্রস গুণ — সম্পূর্ণ নিয়ম
| বিষয় | ডট (A·B) | ক্রস (A × B) |
|---|---|---|
| সূত্র | AB cosθ | AB sinθ n̂ |
| ফল | স্কেলার | ভেক্টর |
| বিনিময় | A·B = B·A | **A×B = −B×A** |
| লম্ব হলে | 0 | সর্বোচ্চ |
| সমান্তরাল হলে | সর্বোচ্চ (AB) | **0** |
| বণ্টন | A·(B+C) = A·B + A·C | A×(B+C) = A×B + A×C |

- **একক ভেক্টর:** î·î = ĵ·ĵ = k̂·k̂ = 1; î·ĵ = ĵ·k̂ = k̂·î = 0; î×ĵ = k̂, ĵ×k̂ = î, k̂×î = ĵ; î×î = 0।
- ডট গুণ (কম্পোনেন্ট): A·B = AxBx + AyBy + AzBz। ক্রস গুণ নির্ণায়ক: |î ĵ k̂; Ax Ay Az; Bx By Bz|।
- (î×k̂) × (ĵ×k̂) = (−ĵ) × î = **k̂**; (î×k̂) × k̂ = −ĵ×k̂ = **−î**।
- **î ও ĵ-এর** যোগফল (লব্ধি) = |î+ĵ| = **√2**, ডট = **0**, ক্রস = |î×ĵ| = **1** ⇒ **লব্ধি > ক্রস > ডট (√2 > 1 > 0)**।
- (A·B)² = A²B² ⇒ cos²θ = 1 ⇒ θ = **0°** (সমান্তরাল)।
- ভেক্টর n̂ = (A×B)/|A×B| ⇒ **−n̂ = (B×A)/|A×B|**।
- **A, B-এর উভয়ের ওপর লম্ব একক ভেক্টর = ± (A×B)/|A×B|**। [SRC: VARSITY_KA] P = 2î+2ĵ−k̂, Q = 6î+3ĵ−3k̂ → P×Q = −3î − 6k̂ ⇒ **± (î + 2k̂)/√5**।
- **দুই ভেক্টরের মধ্যবর্তী কোণ:** θ = cos⁻¹(A·B/AB)। [Varsity লিখিত] A = 2î+2ĵ−k̂, B = 6î−3ĵ+2k̂ → A·B = 12−6−2 = 4; |A| = 3, |B| = 7 → **θ = cos⁻¹(4/21)**।
- দুই ভেক্টরের মান 5 ও 6, কোণ 60° → A·B = **15**; |A×B| = 30·(√3/2) = **15√3**।
- ত্রিভুজের ক্ষেত্রফল = ½|AB × AC|। [Engg] A(1,2,3), B(2,3,1), C(3,1,2) → AB = î+ĵ−2k̂, AC = 2î−ĵ−k̂; সব বাহু √6 ⇒ **ক্ষেত্রফল = (√3/4)(6) = 3√3/2 ≈ 2.598 বর্গ একক**।
- ত্রিভুজের কোণ ভেক্টর দিয়ে: A = 3î+3ĵ−2k̂, B = 4î−2ĵ+3k̂ → A·B = 12−6−6 = 0 ⇒ এক কোণ **90°**; অন্য কোণ 41.055° ও 48.945°।
- **সদৃশ কোণ নির্ণয়:** AB = −2√3 î, AC = −2√3 î + 2ĵ → cosθ = 12/(2√3·4) = √3/2 ⇒ **30°**।
- **তিন ভেক্টর সমতলীয় (coplanar)** হওয়ার শর্ত: **A·(B×C) = 0**।
- দুই বিন্দুর দূরত্ব: P(3,2,5), Q(5,4,a), PQ = 3 ⇒ (a−5)² = 1 ⇒ a = 4 বা 6 (**⚠️ অপশন দেখে বেছে নাও**; বইয়ের উত্তর 4)।

### ১.৫ ডেল (∇) অপারেটর — সম্পূর্ণ তালিকা
- **grad φ = ∇φ = î ∂φ/∂x + ĵ ∂φ/∂y + k̂ ∂φ/∂z** (স্কেলার → ভেক্টর)।
- **div A = ∇·A = ∂Ax/∂x + ∂Ay/∂y + ∂Az/∂z** (ভেক্টর → স্কেলার)।
- **curl A = ∇ × A** (ভেক্টর → ভেক্টর)।
- ল্যাপলাসিয়ান ∇² = ∂²/∂x² + ∂²/∂y² + ∂²/∂z²।
- **∇·V = 0 ⇒ সলিনয়ডাল (আগত ফ্লাক্স = নির্গত ফ্লাক্স)**। **∇×V = 0 ⇒ অঘূর্ণনশীল (irrotational) / সংরক্ষণশীল ক্ষেত্র**। **∇·V > 0 ⇒ তরলের ঘনত্ব হ্রাস, আয়তন বৃদ্ধি**।
- **∇×(∇φ) = 0**, **∇·(∇×A) = 0**।
- **সংরক্ষণশীল বল F ⇒ ∇ × F = 0** (সঠিক সম্পর্ক)। (ভুল অপশন: ∇·F = 0)।
- r = xî+yĵ+zk̂ হলে: ∇·r = 3, ∇×r = 0, ∇r = r̂, **∇(1/r) = −r⃗/r³ ⇒ |∇(1/r)| = 1/r²**, **∇²(1/r) = 0 (r ≠ 0)**, **∇²(ln r) = 1/r² (r ≠ 0, ৩ মাত্রায়)**।
- [Varsity] r = (x+3y)î+(py−z)ĵ+(x−z)k̂ **সলিনয়ডাল** ⇒ ∇·r = 1 + p − 1 = 0 ⇒ **p = 0**।
- [Engg] V = 2xy + x²z² হলে (−2,1,1) বিন্দুতে ∇V = (2y+2xz²)î + 2xĵ + 2x²zk̂ = **−2î −4ĵ + 8k̂**, মান = **2√21 ≈ 9.17**।
- φ = 2x²yz + 2xyz + 2xz³ ⇒ (2,−1,1)-এ ∇φ = −8î + 12ĵ।
- A = 2xz²î − xyĵ + 3xz³k̂ ⇒ (1,1,1)-এ **∇×(∇×A) = 4î + 4k̂**।
- a, b, c কত হলে V = (x+y+az)î + (bx+3y−z)ĵ + (3x+cy+z)k̂ অঘূর্ণনশীল ⇒ **a = 3, b = 1, c = −1** (∇×V = 0 থেকে)।
- স্কেলার ফাংশন → ভেক্টর ক্ষেত্র: **গ্র্যাডিয়েন্ট**; ভেক্টর ক্ষেত্র → স্কেলার: **ডাইভারজেন্স**।
- ভেক্টর যোগের সূত্র: m(P+Q) = mP + mQ = **বণ্টন সূত্র**; (P+Q)+R = P+(Q+R) = **সংযোজন সূত্র**; P+Q = Q+P = বিনিময় সূত্র।

### ১.৬ গতিবিদ্যা — সরলরেখায় গতি
- **v = u + at, s = ut + ½at², v² = u² + 2as**, **s_nth = u + (a/2)(2n − 1)**।
- মুক্তভাবে পড়ন্ত বস্তু: s_nth = (g/2)(2n−1); **5ম ও 10ম সেকেন্ডে অতিক্রান্ত দূরত্বের অনুপাত = 9 : 19** ([SRC: VARSITY_KA])।
- **s = ½t³ + 2t** (t = 4 s) ⇒ v = ds/dt = (3/2)t² + 2 = **26** একক।
- x = 4t²+5t+9 ⇒ v = 8t+5 ⇒ t = 3 s-এ **29 ms⁻¹**।
- x(t) = 2t³ − 3t² + 4t; **ত্বরণ শূন্য** ⇒ a = 12t − 6 = 0 ⇒ t = 0.5 s ⇒ v = 6(0.25) − 3 + 4 = **2.5 ms⁻¹**।
- সমত্বরণে v–t সরলরেখা (y = mx + c-র অনুরূপ); **v–t এর ঢাল = a, ক্ষেত্রফল = সরণ**; s–t ঢাল = v। সমবেগে s–t সরলরেখা; সমমন্দনে s–t উল্টানো পরাবৃত্ত।
- ট্রেন ব্রেকিং: 54 kmh⁻¹ = 15 ms⁻¹, a = 0.75 ms⁻² (মন্দন) ⇒ **s = u²/2a = 225/1.5 = 150 m, t = 15/0.75 = 20 s**।
- স্থির অবস্থান থেকে বিনা বাধায় পড়া: **s ∝ t²** (বেগ ∝ t)।
- **গড় দ্রুতি:** সমান দূরত্ব ⇒ 2v₁v₂/(v₁+v₂) (হারমোনিক); সমান সময় ⇒ (v₁+v₂)/2। [Varsity] অর্ধেক পথ 24 km/h, বাকি পথ u₂, গড় 32 ⇒ **u₂ = 48 km/h**।

### ১.৭ প্রক্ষেপক / প্রাস
- **T = 2u sinα/g, H = u² sin²α/2g, R = u² sin2α/g**।
- **R_max = u²/g (α = 45°)**; **H_max = u²/2g (α = 90°)**; α ও (90°−α) এ **পাল্লা সমান** (60° ও 30° ⇒ সমান পাল্লা)।
- **R = 4H cotα**; α = 45° ⇒ **R = 4H** (সর্বোচ্চ উচ্চতার চার গুণ)।
- **H/t² = g/2** (যেখানে t = সর্বোচ্চ উচ্চতায় উঠার সময়) — [Varsity] উত্তর **g/2**।
- সর্বোচ্চ বিন্দুতে **বেগ অনুভূমিক, ত্বরণ নিম্নমুখী ⇒ বেগ ও ত্বরণ পরস্পর সমকোণে**।
- ব্যক্তি সর্বোচ্চ h উচ্চতা পর্যন্ত ছুঁড়তে পারে ⇒ u² = 2gh; প্রাস হিসেবে নিক্ষেপ ⇒ R = u²/g = **2h**।
- অনুভূমিক নিক্ষেপ: **t = √(2h/g)**, x = vₓt। [Varsity লিখিত] মিনারের শীর্ষ থেকে 980 ms⁻¹ বেগে অনুভূমিক গুলি, 2 s পরে ভূমি স্পর্শ ⇒ **উচ্চতা h = ½·9.8·4 = 19.6 m, দূরত্ব = 980×2 = 1960 m**।
- কোণ নিক্ষেপ: প্রতি মুহূর্তে অনুভূমিক বেগ **স্থির**, উল্লম্ব বেগ বদলায়; ত্বরণ **g (নিচের দিকে)**।
- উল্লম্বভাবে 40 ms⁻¹-এ ছুঁড়ে ফিরে এলে **গড় বেগ = 0** (সরণ শূন্য)।
- **তাৎক্ষণিক বেগ বনাম সরণ ফাংশন:** সরণ ⇒ x(t), বেগ ⇒ dx/dt, ত্বরণ ⇒ d²x/dt² (**বেগের time derivative = ত্বরণ**; সরণের time derivative = বেগ)।

### ১.৮ আপেক্ষিক বেগ — নদী-নৌকা, বৃষ্টি-ছাতা
**নদী-নৌকা:** নৌকার বেগ v, স্রোত u, নদীর প্রস্থ d।
| উদ্দেশ্য | কোণ (স্রোতের সাথে α) | সময় | মন্তব্য |
|---|---|---|---|
| **ন্যূনতম সময়** (সোজা সামনে) | α = 90° | t = d/v | অতিক্রান্ত পথ = √(v²+u²)·t |
| **ন্যূনতম দূরত্ব** (সোজাসুজি অপর পাড়ে, v > u) | cosα = −u/v | t = d/√(v²−u²) | অপর পাড়ে সোজা |
- [Varsity] v = 4, u = 3, d = 80 m ⇒ ন্যূনতম সময় = 20 s; দূরত্ব = 5 × 20 = **100 m**।
- v = 10, u = 6, d = 192 m ⇒ ন্যূনতম দূরত্বে সময় t = 192/√(100−36) = **24 s**।
- v = 12, u = 6 ⇒ cosα = −1/2 ⇒ **α = 120°** সোজা অপর পাড়ে যেতে।
- [Engg লিখিত] v = 14 km/h, u = 7 km/h ⇒ cosα = −1/2 ⇒ **120°**; প্রস্থ 12.125 km ⇒ t ≈ 1 h। v = 4, u = 1 ⇒ cosα = −1/4 ⇒ α = 104.48°, d = 9.68 km (t = 2.5 h)। অনুকূল 24, প্রতিকূল 12 km/h ⇒ v = 18, u = 6 ⇒ α = 109.5°, t = 3.53 min।
- আরেক নৌকা সূত্র: **মূল প্রশ্নে সোজাসুজি পার** হলে স্রোতের বেগের উপাংশ শূন্য: u + v cosα = 0।
- সাঁতারু: v_s = √2·u, সোজাসুজি অপর পাড়ে ⇒ cosα = −u/(√2u) = −1/√2 ⇒ **α = 135°** ([SRC: MEDICAL_UNMESH])।

**বৃষ্টি-ছাতা:**
- ব্যক্তি 5 ms⁻¹-এ হাঁটছে, বৃষ্টি 10 ms⁻¹-এ **উল্লম্বভাবে** পড়ছে ⇒ ছাতা **উল্লম্বের সাথে tan⁻¹(5/10) = tan⁻¹(1/2)** কোণে; অনুভূমিকের সাথে **90° − tan⁻¹(1/2)** (Varsity MCQ-তে এটিই উত্তর)।
- ব্যক্তি 2 ms⁻¹ ও 4 ms⁻¹-এ চলার সময় বৃষ্টি উল্লম্বভাবে ও 45° কোণে ⇒ **v_r cosα = −2**, **v_r sinα = 2** ⇒ v_r = **2√2 ms⁻¹**, α = **135°** (Engg)।
- 3 ms⁻¹ ও 5 ms⁻¹ ⇒ উল্লম্বে ও 30° কোণে ⇒ v_r = **√21 = 4.58 ms⁻¹**, উল্লম্বের সাথে **40.9°**।
- 10 km/h বৃষ্টি (উল্লম্ব), পূর্ব→পশ্চিমে 60 km/h বাতাস: পেছনের কাচ ভিজবে না যদি v_C ≥ 60 (দুই কাচই না ভিজতে **v_C = 60**); শুধু পেছনের কাচ ভিজবে ⇒ **v_C < 60**।

### ১.৯ বৃত্তীয় গতি
- **ω = θ/t = 2π/T = 2πN/t = 2πf**, **v = ωr**, **a_c = v²/r = ω²r = vω** (কেন্দ্রমুখী ত্বরণ)।
- সমদ্রুতি বৃত্তীয় গতিতে **a ∝ 1/r (v ধ্রুবক)**, a·r = ধ্রুবক ⇒ a–r লেখ **আয়তাকার অধিবৃত্ত (hyperbola)**।
- ঘূর্ণন সংখ্যা: **N = θ/2π**; সমমন্দনে **θ = ((ω₀ + 0)/2)·t**।
- [Varsity MCQ] পাখা 1200 rpm ⇒ ω₀ = 40π rad/s; সুইচ বন্ধের 2 min (120 s) পরে থামে ⇒ **θ = 2400π rad = 1200 rev**।
- চাকার ব্যাস 1 m, 30 rpm ⇒ **v = π/2 ms⁻¹**।
- ঘড়ির মিনিটের কাঁটা ⇒ ω = 2π/3600 = **π/1800 rad s⁻¹**; ঘণ্টার কাঁটা ⇒ ω = π/360 rad min⁻¹।
- r = 2.0 m বৃত্তে 30 বার/মিনিট ⇒ v = 2πrn/t = 2π×2×30/60 = **2π ms⁻¹**।
- **কৌণিক বেগ: মাত্রা [T⁻¹], একক rad s⁻¹, ভেক্টর রাশি** (⚠️ [LT⁻¹] হলো রৈখিক বেগের মাত্রা)। [SRC: MEDICAL_UNMESH] বইয়ের ভুল বিকল্প: "বস্তু কৌণিক বেগে চললে এর রৈখিক বেগ থাকে না" — সঠিক হলো **কৌণিক বেগে ঘুরলেও রৈখিক বেগ থাকে (v = ωr), কিন্তু সমরৈখিক বেগে চললে রৈখিক ত্বরণ থাকে না, কেন্দ্রমুখী ত্বরণ থাকে বৃত্তে**।
- কেন্দ্রমুখী ও কেন্দ্রবিমুখী বলের ব্যবহারিক উদাহরণ: রাস্তার বাঁকে ব্যাঙ্কিং, সাইকেল আরোহীর বাঁক নেওয়া, গ্রহের গতি। **গুণ টেনে নৌকা চালানো কেন্দ্রমুখী/কেন্দ্রবিমুখী বলের দৃষ্টান্ত নয়** — এটি বল বিভাজনের (ভেক্টর বিভাজনের) দৃষ্টান্ত।

### ১.১০ নিউটনের সূত্র ও ভরবেগ [SRC: MEDICAL_UNMESH]
- **ঘাত = F·t = ভরবেগের পরিবর্তন**: 10 N × 4 s = **40 kg ms⁻¹**; 4 N × 1 s = **4 kg ms⁻¹**।
- **লিফটে ওজন:** নামলে **F = m(g − a)**, উঠলে **F = m(g + a)**। 65 kg, a = 1 ms⁻² (নিচে) ⇒ **572 N**; 90 kg, a = 2.2 ⇒ **684 N**।
- **ওজন ও ত্বরণ:** W = 588 N ⇒ m = 60 kg; a = 0.70 ⇒ F = **42 N**।
- **রিকয়েল:** MV + mv = 0 ⇒ V = −mv/M; 0.01 kg গুলি 300 ms⁻¹, বন্দুক 6 kg ⇒ **|V| = 0.5 ms⁻¹** (⚠️ প্রশ্নে "পশ্চাদ্বেগ" থাকলে উত্তর ধনাত্মক)।
- **স্থিতিস্থাপক সংঘর্ষ:** ভর সমান, দ্বিতীয়টি স্থির ⇒ সংঘর্ষের পর প্রথমটি থেমে যায়, **দ্বিতীয়টি v₁ বেগে চলে**।
- **স্থিতিস্থাপক সংঘর্ষে ভরবেগ ও গতিশক্তি উভয়ই সংরক্ষিত**; অস্থিতিস্থাপকে **শুধু ভরবেগ**।
- **ঘর্ষণ চার প্রকার:** স্থিতি, গতীয়, আবর্ত, প্রবাহী। **স্থিতি ঘর্ষণ:** গতির বিরুদ্ধে ক্রিয়াশীল, **স্পর্শতলের প্রকৃতির ওপর নির্ভর**, **ক্ষেত্রফলের ওপর নির্ভর করে না**; সীমান্তিক মান অভিলম্ব প্রতিক্রিয়ার সমানুপাতিক। **ঘর্ষণ বল সংরক্ষণশীল নয়** (**অসংরক্ষণশীল**)। ঘর্ষণ বল ও বেগের মধ্যবর্তী কোণ **π**; ঘর্ষণ গুণাঙ্কের একক নেই।
- **সাইকেলের বেগ ও চাকার ঘর্ষণের মধ্যবর্তী কোণ = π**।
- **টানা নৌকা:** গুণ টানার সময় নৌকা সামনে যায় **টানার অনুভূমিক উপাংশের জন্য**; উল্লম্ব উপাংশ হাল দিয়ে প্রশমিত।
- **রকেট:** a = (1/M)(Δm/Δt)·V_r − g; **ভর কমলে ত্বরণ বাড়ে**, ভর বাড়লে কমে।

### ১.১১ ঘূর্ণন (মেডিকেল-অতিরিক্ত)
- **টর্ক τ = r × F = Iα = dL/dt** ⇒ **কৌণিক ভরবেগের পরিবর্তনের হার = টর্ক**। **[τ] = ML²T⁻²**।
- **L = r × p = Iω**; **[L] = ML²T⁻¹**।
- জড়তার ভ্রামক **I = Mk²** (k = চক্রগতির ব্যাসার্ধ)। ১ম: ভর 20 g, অক্ষ থেকে 1 m ⇒ **I = 0.02 kg m²**। ২য়: M = 5 kg, k = 0.2 m ⇒ I = 0.2 kg m²; α = 2 rad s⁻² ⇒ **τ = 0.4 N m**।
- জড়তার ভ্রামক **নির্ভর করে না:** দৃঢ় বস্তুর **কৌণিক বেগের ওপর**। **নির্ভর করে:** ঘূর্ণন অক্ষের অবস্থান, বস্তুর আকৃতি, **ভরের বিন্যাস**।
- **সমান্তরাল অক্ষ উপপাদ্য: I = I_G + Mh²**; **লম্ব অক্ষ উপপাদ্য: I_z = I_x + I_y** (সমতলীয় বস্তু)।
- বৃত্তাকার চাকতি: কেন্দ্রগামী লম্ব অক্ষে **I = ½Mr²**; **ব্যাস সাপেক্ষে I = ¼Mr²**।
- সুষম সরু দণ্ড: কেন্দ্রে I = Ml²/12, প্রান্তে I = Ml²/3 ⇒ অক্ষ কেন্দ্র থেকে প্রান্তে সরালে **I চার গুণ** ⇒ ঘূর্ণন গতিশক্তি চার গুণ ⇒ থামাতে **চার গুণ** বাধার সম্মুখীন হতে হয়।
- **ঘূর্ণন গতিতে ভর-এর ভূমিকা পালন করে → জড়তার ভ্রামক**; সরল গতির F = ma ↔ ঘূর্ণনের τ = Iα।
- **কেন্দ্রমুখী বলের রাশিমালা: mω²r = mv²/r**।

### ১.১২ মৌলিক বল ও এককের মাত্রা (সংক্ষেপ)
- চার মৌলিক বল (Varsity/Medical): **সবল নিউক্লীয়, তড়িৎচুম্বকীয়, দুর্বল নিউক্লীয়, মহাকর্ষ**।
- মহাকর্ষ বলের তীব্রতা = 1 ধরলে: **সবল নিউক্লীয় ≈ 10⁴¹ (বইয়ের মান), তড়িৎচুম্বকীয় ≈ 10³⁹, দুর্বল নিউক্লীয় ≈ 10³⁰** (⚠️ বই-ভেদে সামান্য ভিন্ন, পরীক্ষায় দেওয়া মান অনুযায়ী লেখো)।
- **সালাম–ভাইনবার্গ তত্ত্ব:** তড়িৎচুম্বকীয় + দুর্বল নিউক্লীয় বলের একীকরণ।
- **নিউক্লিয়াসের ভেতরে** প্রোটন-প্রোটন, প্রোটন-নিউট্রন, নিউট্রন-নিউট্রন-এর মধ্যে **সবল নিউক্লীয় বল**; নিউট্রন চার্জহীন বলে সেখানে তড়িৎচুম্বকীয় বল কাজ করে না। **দুর্বল নিউক্লীয় বল** ⇒ তেজস্ক্রিয়তা (β ক্ষয়)।
- মাত্রা: [বল] = MLT⁻², [কাজ/শক্তি] = ML²T⁻², [ভরবেগ/ঘাত] = MLT⁻¹, [কৌণিক বেগ] = T⁻¹।

### ৩.২ Medical Fact Box (সরাসরি তথ্য — মুখস্থ)
- **ভেক্টর ও স্কেলার:** বল, টর্ক, কৌণিক ভরবেগ → ভেক্টর। স্থিতিশক্তি, তড়িৎ প্রবাহ, দ্রুতি, তড়িৎ বিভব → **স্কেলার**।
- **বল কোনো স্কেলার রাশি নয়।**
- **ডাইভারজেন্স ধনাত্মক ⇒ তরলের ঘনত্ব হ্রাস।**
- **কার্ল শূন্য ⇒ অঘূর্ণনশীল ক্ষেত্র; ডাইভারজেন্স শূন্য ⇒ সলিনয়ডাল।**
- **ভেক্টর (বল) বিভাজনের দৃষ্টান্ত:** লন রোলার টানা, পাখির ওড়া, নৌকার গুণ টানা, পায়ে হাঁটা।
- **"চলন্ত গাড়িতে পড়ন্ত বৃষ্টি" বিভাজনের নয়**, এটি **ভেক্টর বিয়োগ/আপেক্ষিক বেগের** দৃষ্টান্ত (Varsity MCQ-তে "ভেক্টর বিভাজনের দৃষ্টান্ত নয় কোনটি?" → উত্তর: চলন্ত গাড়িতে পড়ন্ত বৃষ্টি)।
- **কৌণিক বেগের একক: rad s⁻¹**; মাত্রা **[T⁻¹]**; **ভেক্টর রাশি**।
- **ঘর্ষণ চার প্রকার**, **স্পর্শতলের ক্ষেত্রফলের উপর নির্ভর করে না।**
- **ঘাত = ভরবেগের পরিবর্তন**; ঘাতের মাত্রা MLT⁻¹।
- **[τ] = ML²T⁻²; [L] = ML²T⁻¹; [I] = ML²**।
- **টর্ক = কৌণিক ভরবেগের পরিবর্তনের হার।**
- **মৌলিক বল:** সবল > তড়িৎচুম্বকীয় > দুর্বল > মহাকর্ষ।
- **ক্রস গুণ:** **A × B = 0 হলে সমরেখ/সমান্তরাল**; A·(B×C) = 0 হলে **সমতলীয়**।
