## ১. ওয়ান-স্টপ মাস্টার হ্যান্ডনোট

### ক. ল্যাবরেটরির নিরাপদ ব্যবহার (১ম পত্র, অধ্যায় ১)

#### ১.১ হ্যাজার্ড (বিপদ) প্রতীক — সম্পূর্ণ তালিকা
| প্রতীক | অর্থ | উদাহরণ (Week_01 ডেটা থেকে) |
|---|---|---|
| **F** | দাহ্য (Flammable) | এরোসল, পেট্রোলিয়াম, LPG, জৈব দ্রাবক |
| **E** | বিস্ফোরক (Explosive) | **TNT**, জৈব পার-অক্সাইড |
| **O** | জারক (Oxidizing) | **KMnO₄ (কঠিন)**, K₂Cr₂O₇ |
| **T** | বিষাক্ত (Toxic) | K₂Cr₂O₇ গুঁড়া (O/T) |
| **C** | ক্ষয়কারী (Corrosive) | **গাঢ় H₂SO₄**, NaOH |
| **N** | পরিবেশ দূষক | **NH₃ গ্যাস** |
| **Xi** | উত্তেজক (Irritant) | **সিমেন্ট গুঁড়া, বিরঞ্জক পদার্থ** |
- **MSDS = Material Safety Data Sheet** (রাসায়নিকের নাম, সতর্ক ব্যবহার, ঝুঁকি, নিরাপত্তা সতর্কতা)। **AAS = Atomic Absorption Spectroscopy**।
- **ডেকন-৯০ (Decon-90)** = **পরিষ্কারক ডিটারজেন্ট** (⚠️ "ডেকন-৯০ কী?" → পরিষ্কারক ডিটারজেন্ট)।

#### ১.২ পরিষ্কারক মিশ্রণ ও অ্যাকোয়া রেজিয়া
- **অ্যাকোয়া রেজিয়া (রাজঅম্ল):** **গাঢ় HNO₃ : গাঢ় HCl = 1 : 3**। (Varsity MCQ-তে "ক্রোমিক অ্যাসিড মিশ্রণ কোনটি?" প্রশ্নের অপশনে HNO₃+HCl মিশ্রণ ভুল বিকল্প হিসেবে দেওয়া — সঠিক উত্তর: **conc. K₂Cr₂O₇ + conc. H₂SO₄**।)
- **ক্রোমিক অ্যাসিড মিশ্রণ (ক্লিনিং মিক্সার):** **গাঢ় K₂Cr₂O₇ + গাঢ় H₂SO₄**। কাচের যন্ত্রপাতি থেকে **তৈলাক্ত পদার্থ** ধুতে ব্যবহৃত। ⚠️ [SRC: ENGG_EXTRA] লিখিতে সংযুতি: **K₂Cr₂O₇ 4 g, পাতিত পানি 40 mL, গাঢ় H₂SO₄ 40 mL** (ডেটা অনুযায়ী; বইভেদে পরিমাণ মিলিয়ে নাও)।
- **দীর্ঘ ব্যবহারের পর ক্লিনিং মিশ্রণ সবুজ রং** ধারণ করে — কারণ: **Cr₂O₇²⁻ (কমলা) → Cr³⁺ (সবুজ)** (গাঢ় H₂SO₄-এর প্রভাবে বিজারিত):
  **4H₂SO₄ + K₂Cr₂O₇ → K₂SO₄ + Cr₂(SO₄)₃ + 4H₂O + 3[O]**।
- **নিরাপদ বিকল্প:** টলুইনের পরিবর্তে **জাইলিন**; লেড ক্রোমেটের বিকল্প হিসেবে বইয়ের উত্তর **পটাসিয়াম কার্বনেট** (⚠️ ডেটা অনুযায়ী); পরিত্যক্ত **ক্ষারক প্রশমিত করতে NaHSO₄** (জলীয় দ্রবণ)।
- **অব্যবহৃত LiAlH₄ নষ্ট করতে** জলীয় **MgSO₄ দ্রবণ** (Varsity বই অনুযায়ী)।
- **উত্তেজক পদার্থ:** সিমেন্ট গুঁড়া। **জৈব দ্রাবক** **দাহ্য**।

#### ১.৩ যন্ত্রপাতি ও ব্যবহার
| যন্ত্র | প্রধান কাজ |
|---|---|
| **পিপেট** | নির্দিষ্ট আয়তনের দ্রবণ এক পাত্র থেকে অন্য পাত্রে নেওয়া |
| **বুরেট** | টাইট্রেশনে দ্রবণ ফোঁটা ফোঁটা যোগ করা, **দুই দ্রবণের সমতুল্য আয়তন সূক্ষ্মভাবে মাপা** |
| **কনিক্যাল ফ্লাস্ক** | আয়তনিক বিশ্লেষণে টাইট্রেশন বিক্রিয়া ঘটানো |
| **মেজারিং সিলিন্ডার** | বিভিন্ন আয়তনের তরল মাপা (**কম নির্ভুল**) |
| **মেজারিং ফ্লাস্ক** | নির্দিষ্ট আয়তনের **প্রমাণ দ্রবণ প্রস্তুত** |
- তরল পদার্থের **সূক্ষ্ম আয়তন মাপের** জন্য সেট: **পিপেট ও বুরেট** (Varsity MCQ: "টাইট্রেশনকালে সূক্ষ্ম আয়তন মাপার সেট → বুরেট ও পিপেট")।
- **দাগকাটা পিপেট ও কনিক্যাল ফ্লাস্ক নয়**; **পিপেট ও বুরেট** সঠিক সেট।

#### ১.৪ পল-বুঙ্গি (Pol-Bungy) / বিশ্লেষণাত্মক নিক্তি
- **রাইডারের ধ্রুবক / ক্ষমতা:** **ধ্রুবক = রাইডার (mg) × 2 / 100**।
  - 5 mg রাইডার ⇒ **0.1 mg = 0.0001 g**; 30 mg ⇒ **0.6 mg = 0.0006 g**।
- **সেমিমাইক্রো বিশ্লেষণ:** গৃহীত বস্তুর ভর **50 mg – 200 mg**।
- **ব্যালান্সের ক্ষমতা মানে** রাইডার-ক্ষমতা অনুপাত; উত্তরে "ক্ষমতা" শব্দ থাকলে g একক লক্ষ্য করো।

#### ১.৫ নির্দেশক ও টাইট্রেশন
| টাইট্রেশন | উপযুক্ত নির্দেশক |
|---|---|
| **শক্তিশালী অ্যাসিড + শক্তিশালী ক্ষার** | মিথাইল অরেঞ্জ, মিথাইল রেড, ফেনল্ফথ্যালিন (সবই চলে) |
| **দুর্বল অ্যাসিড + শক্তিশালী ক্ষার** (যেমন HCOOH + Ca(OH)₂) | **ফেনল্ফথ্যালিন** |
| **শক্তিশালী অ্যাসিড + দুর্বল ক্ষার** | মিথাইল রেড / মিথাইল অরেঞ্জ |
| **দুর্বল অ্যাসিড + দুর্বল ক্ষার** (CH₃COOH + NH₄OH) | **কোনো নির্দেশক কার্যকর নয়** |
| **রেডক্স টাইট্রেশনে KMnO₄** | **নির্দেশকের প্রয়োজন নেই (স্ব-নির্দেশক)** — "সুবিধা" |
- **pH পরিসর:** **ফেনল্ফথ্যালিন 8.2 – 9.8**; **ক্রিসল রেড 7.2 – 8.8**; মিথাইল অরেঞ্জ 3.1 – 4.4; মিথাইল রেড 4.4 – 6.2 (শেষ দুটি স্ট্যান্ডার্ড মান; ডেটায় সরাসরি নেই)।
- **ডাইফিনাইলঅ্যামিন** K₂Cr₂O₇ টাইট্রেশনের নির্দেশক; **H₃PO₄ যোগ করতে হয়** (Fe³⁺-এর সাথে বর্ণহীন জটিল আয়ন [Fe(HPO₄)]⁺ গঠনে)।
- **টাইট্রেশনে K₂Cr₂O₇-এর সুবিধা:** প্রাইমারি স্ট্যান্ডার্ড, রাসায়নিক নিক্তিতে সঠিক ওজন করা যায়, জলীয় দ্রবণ দীর্ঘদিন অপরিবর্তিত, আলো/জৈব যৌগ/লঘু HCl দ্বারা বিজারিত হয় না। **অসুবিধা:** KMnO₄-এর মতো স্ব-নির্দেশক নয়; অনুজ্জ্বল বিক্রিয়া; H₃PO₄ লাগে।

### খ. পরিমাণগত রসায়ন (২য় পত্র, অধ্যায় ৩)

#### ১.৬ মৌলিক সূত্র
- **STP (0 °C, 1 atm)**: 1 mol গ্যাস = **22.4 L**; **N_A = 6.023 × 10²³**।
- **n = W/M = V_STP/22.4 = N/N_A**।
- **একই ভরে গ্যাসের আয়তন ∝ 1/M** ⇒ STP-তে 1 g গ্যাসের মধ্যে **H₂ সবচেয়ে বেশি আয়তন** দখল করে (M = 2)।
- **44 g N₂O (M = 44) ⇒ STP-তে 22.4 L**।
- **স্বাভাবিক গ্যাস সমীকরণ:** PV = nRT; R = 0.0821 L atm mol⁻¹K⁻¹। [Engg] 37 °C, 1 atm, n = 0.374 mol ⇒ V = 9.52 L।
- **সংখ্যা তুলনা (Varsity):** 1.10 g H, 14.7 g Cr, 2.0 g He, 7.0 g N → পরমাণু সংখ্যা: H = 6.63×10²³ (1.1 g → 1.1×6.023×10²³), Cr = 1.7×10²³, He = 3.01×10²³, N = 3.01×10²³ ⇒ **(b) 14.7 g Cr পরমাণুতে সবচেয়ে কম পরমাণু সংখ্যা**।

#### ১.৭ ঘনমাত্রা — সব একক
| একক | সূত্র | নির্ভরতা |
|---|---|---|
| **মোলারিটি (M)** | mol/L = **10x/M** (x = %w/v) | **তাপমাত্রা-নির্ভর** |
| **মোলালিটি (m)** | mol/kg দ্রাবক | **তাপমাত্রা-নিরপেক্ষ** |
| **নরমালিটি (N)** | **N = S × e** (S = M, e = সক্রিয় গ্রাম/মোল) | তাপমাত্রা-নির্ভর |
| **শতকরা %(w/w)** | ভর-ভিত্তিক | **তাপমাত্রা-নিরপেক্ষ** |
| **%(w/v)** | আয়তন-ভিত্তিক | তাপমাত্রা-নির্ভর |
| **ppm** | **M × আণবিক ভর × 1000 mg/L** | — |
- 13.25 % (w/v) Na₂CO₃ ⇒ **10 × 13.25/106 = 1.25 M**।
- 16 % (w/v) NaOH ⇒ **10 × 16/40 = 4 M**।
- 250 mL 0.1 N NaOH ⇒ **W = N·V·M/(1000·e) = 0.1×250×40/1000 = 1.0 g**।
- ডেসিমোলার (0.1 M), আণবিক ভর 106, 250 mL ⇒ **W = SMV/1000 = 0.1×106×250/1000 = 2.65 g**।
- **সম্পৃক্ত দ্রবণে মোলালিটি তাপমাত্রা বাড়লে "পরিবর্তন হবে না"** (14 °C/2m → 2 °C বৃদ্ধি) — কারণ **মোলালিটি তাপমাত্রা-নিরপেক্ষ**।
- ⚠️ **তাপমাত্রা-নিরপেক্ষ ঘনমাত্রা** প্রশ্নে: %(w/w) ও মোলালিটি; **নির্ভরশীল**: মোলারিটি, %(w/v)।

#### ১.৮ প্রশমন/টাইট্রেশন সমীকরণ
- **সাধারণ সূত্র:** **S_A V_A / (n_A) = S_B V_B / (n_B)** (n = বিক্রিয়ায় মোল সংখ্যা)।
- **n_e সমতা:** **(S × V × e)_অম্ল = (S × V × e)_ক্ষার**।
- 25 mL 0.2 M H₃PO₄ ⇒ 0.1 M Na₂CO₃ লাগে **V = (3 × 0.2 × 25)/(2 × 0.1) = 75 mL** (H₃PO₄ → 3 H⁺, Na₂CO₃ → 2 OH⁻ সমতুল্য)।
- 50 mL 0.1 M Ca(OH)₂ প্রশমিত করতে 25 mL H₃PO₄ ⇒ **S = (2×0.1×50)/(3×25) = 0.1333 M**।
- **মিশ্রণের প্রকৃতি:** 10 mL 1 M H₂SO₄ ≡ **20 mL 1M H⁺**; 50 mL 0.5 N NaOH ≡ **25 mL 1M OH⁻** ⇒ ক্ষার বেশি ⇒ মিশ্রণ **ক্ষারীয়** ([SRC: VARSITY_KA] Q21)।
- **বিক্রিয়া শেষে অবশিষ্ট ঘনমাত্রা:** 50 mL 2M NaOH + 50 mL 1M HCl ⇒ **S′ = (50×2 − 50×1)/100 = 0.5 M ⇒ ppm = 0.5 × 40 × 1000 = 2 × 10⁴ ppm**।
- **লিমিটিং বিক্রিয়ক:** প্রয়োজনীয় মোল অনুপাতের চেয়ে কম মাত্রায় থাকা বিক্রিয়ক; উৎপাদের পরিমাণ **তার** ওপর নির্ভর করে।
- **শতকরা বিশুদ্ধতা = (বিশুদ্ধ ভর / নমুনা ভর) × 100**।
  - 400 g চুনাপাথর নমুনা থেকে 67.2 L CO₂ ⇒ n = 3 mol ⇒ 300 g CaCO₃ ⇒ **বিশুদ্ধতা 75 %**।
  - 90 % বিশুদ্ধ 444.44 g নমুনা ⇒ 400 g CaCO₃ ⇒ **89.6 L CO₂ (STP)**।
  - 8 g CaCO₃ + MgCO₃ মিশ্রণ থেকে 1.922 L CO₂: x/100 + (8−x)/84 = 1.922/22.4 ⇒ x ≈ 4.953 g ⇒ **CaCO₃ ≈ 61.91 %**; তাপে বিয়োজনে 1.11 L CO₂।
- **মোল সূত্র (স্টোইকিওমেট্রি):**
  - 2KClO₃ → 2KCl + 3O₂: **122.5 g KClO₃ ⇒ 33.6 L O₂ (STP)**; 16.8 L O₂ পেতে **61.25 g KClO₃**।
  - 2HgO → 2Hg + O₂: 1.5 mol O₂ ⇒ **648 g HgO**।
  - MgCO₃ + 2HCl: **1 kg MgCO₃ ⇒ (22.4/84)×1000 = 800/3 ≈ 266.7 L CO₂**।
  - 134.4 L O₂ প্রস্তুতি: (134.4/67.2) × 245 = **490 g KClO₃** ([SRC: VARSITY_KA] Q26)।
- **মৌলিক বিশ্লেষণ:** 0.5 g জৈব যৌগ ⇒ 0.9 g CO₂ ও 0.3 g H₂O ⇒ C = 0.9×12/44 = 0.2455 g; H = 0.3×2/18 = 0.0333 g; **O = 0.5 − 0.2788 = 0.2212 g ⇒ 44 %**।
- **ইউডিওমেট্রি (হাইড্রোকার্বন সংকেত):** CxHy + (x + y/4)O₂ → xCO₂ + (y/2)H₂O। KOH/NaOH → **CO₂ শোষণ**; CaO → CO₂ শোষণ; ঠান্ডা করলে **H₂O তরল (আয়তন বাদ)**।
  - [Engg] 16 mL গ্যাস, মোট 214 mL → ঠান্ডা 158 mL → KOH-এর পর 94 mL ⇒ **C₄H₁₀**।
  - 20 mL গ্যাস, মোট 90 mL, ঠান্ডা 50 mL, CaO-এর পর 40 mL ⇒ **C₂H₄**।

#### ১.৯ জারণ–বিজারণ
- **জারক:** ইলেকট্রন **গ্রহণ**, নিজে **বিজারিত**; **বিজারক:** ইলেকট্রন **ত্যাগ**, নিজে **জারিত**।
- **জারণ সংখ্যা:** **Ca(OCl)Cl-এ Cl: +1 ও −1**; **H₂SO₅ (পার-অক্সি) এ S = +6** (পার-অক্সি O–O বন্ধন, O = −1); **S₂O₃²⁻ ⇒ +2**; **S₄O₆²⁻ ⇒ +2.5**।
- **প্রতি অণুতে ইলেকট্রন গ্রহণ (বিজারণ):**
  | জারক | মাধ্যম | e⁻ সংখ্যা |
  |---|---|---|
  | KMnO₄ (MnO₄⁻) | অম্লীয় → Mn²⁺ | **5** |
  | KMnO₄ | ক্ষারীয়/প্রশম → MnO₂ | **3** |
  | **H₂O₂** | অম্লীয় → H₂O | **2** |
  | K₂Cr₂O₇ | অম্লীয় → 2Cr³⁺ | **6** |
- **জারণ–বিজারণ সমীকরণ (সমতাকৃত):**
  - **2KMnO₄ + 3H₂SO₄ + 5H₂S → K₂SO₄ + 2MnSO₄ + 8H₂O + 5S** ⇒ সহগ **2, 3, 5, 1, 2, 8**।
  - **3C₂O₄²⁻ + Cr₂O₇²⁻ + 14H⁺ → 6CO₂ + 2Cr³⁺ + 7H₂O** ⇒ **3, 1, 14, 6, 2, 7**।
  - **2Na₂S₂O₃ + I₂ → Na₂S₄O₆ + 2NaI**।
  - **SnCl₂ + 2HgCl₂ → SnCl₄ + Hg₂Cl₂** (2HgCl): **Sn²⁺ জারিত**।
  - **K₂Cr₂O₇ + 3H₂C₂O₄ + 4H₂SO₄ → Cr₂(SO₄)₃ + K₂SO₄ + 7H₂O + 6CO₂**।
  - **6FeSO₄ + K₂Cr₂O₇ + 7H₂SO₄ → 3Fe₂(SO₄)₃ + Cr₂(SO₄)₃ + K₂SO₄ + 7H₂O**।
  - **2KMnO₄ + 5H₂O₂ + 3H₂SO₄ → 5O₂ + 2MnSO₄ + K₂SO₄ + 8H₂O**; K₂Cr₂O₇ + 3H₂O₂ + 4H₂SO₄ → Cr₂(SO₄)₃ + 7H₂O + K₂SO₄ + 3O₂।

  - ক্ষারীয় মাধ্যম: **3Cl⁻ + 4H₂O + 2NO₃⁻ → 3HClO + 2NO + 5OH⁻**।
  - অম্লীয়: **I₂ + 10NO₃⁻ + 8H⁺ → 2IO₃⁻ + 10NO₂ + 4H₂O**।
- **Disproportionation (স্ব-জারণ-বিজারণ):** **Cl₂ + 2OH⁻ → Cl⁻ + ClO⁻ + H₂O** (Cl: 0 → −1 ও +1)।
- **অবস্থাভেদে জারক/বিজারক উভয়:** **H₂O₂**, **FeO** (Fe²⁺)। **তরল জারক:** **H₂O₂**; **গ্যাসীয় বিজারক:** **H₂**; **কঠিন জারক নয়:** FeCl₂ (**FeCl₂ কঠিন জারক নয়**); **অবস্থাভেদে জারক ও বিজারক নয়:** F₂, HF (F সর্বোচ্চ তড়িৎ ঋণাত্মক, কেবল জারক)।
- **নিয়ম:** K₂Cr₂O₇ ⇒ **KMnO₄-এর মতো শক্তিশালী নয়** (E° = 1.33 V বনাম 1.52 V)।

  |---|---|---|
  | লাইম্যান | 1 | **UV** |

- **আউফবাউ ও (n+l):** 4s (4) < 3d (5) < 4p (5) [n+l সমান হলে ছোট n আগে]; 5s (5) < 4d (6) = 5p (6) ⇒ **5s < 4d < 5p**।
