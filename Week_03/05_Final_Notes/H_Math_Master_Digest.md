## ১. ওয়ান-স্টপ কোর থিওরি ও অ্যাডভান্সড ফর্মুলা ম্যাট্রিক্স

### ১.১ কণিক পরিচিতি ও সাধারণ সমীকরণ
- **কণিকের জ্যামিতিক সংজ্ঞা:** সমতলে একটি নির্দিষ্ট স্থির বিন্দু (উপকেন্দ্র, $S$) এবং একটি নির্দিষ্ট সরলরেখা (নিয়ামক বা দিকাক্ষ, $MZ$) হতে যে চলমান বিন্দুর ($P$) দূরত্বের অনুপাত সর্বদা ধ্রুবক, তার সঞ্চারপথকে কণিক বলে।
  $$\frac{SP}{PM} = e \quad (	ext{ধ্রুবক, উৎকেন্দ্রিকতা / Eccentricity})$$
- **উৎকেন্দ্রিকতার ($e$) মান ও কনিক শনাক্তকরণ:**
  - $e = 0 \implies$ **বৃত্ত (Circle)**
  - $0 < e < 1 \implies$ **উপবৃত্ত (Ellipse)**
  - $e = 1 \implies$ **পরাবৃত্ত (Parabola)**
  - $e > 1 \implies$ **অধিবৃত্ত (Hyperbola)**
  - $e = \sqrt{2} \implies$ **সমপরাবৃত্ত বা আয়তাকার অধিবৃত্ত (Rectangular Hyperbola)**
  - $e = \infty \implies$ **একজোড়া সমান্তরাল সরলরেখা (Pair of Parallel Straight Lines)**
- **দ্বিঘাত সাধারণ সমীকরণ $ax^2 + 2hxy + by^2 + 2gx + 2fy + c = 0$ হতে কনিক চেনার নিয়ম:**
  - নিরূপক $\Delta = abc + 2fgh - af^2 - bg^2 - ch^2 
eq 0$ হলে:
    1. $h^2 - ab = 0 \implies$ **পরাবৃত্ত**
    2. $h^2 - ab < 0$ এবং $a 
eq b \implies$ **উপবৃত্ত** ($a = b$ ও $h = 0$ হলে বৃত্ত)
    3. $h^2 - ab > 0 \implies$ **অধিবৃত্ত** ($a + b = 0$ হলে সমপরাবৃত্ত)

### ১.২ পরাবৃত্ত (Parabola — $e = 1$)
- **প্রমিত সমীকরণদ্বয়ের তুলনামূলক চার্ট:**

| প্যারামিটার / বৈশিষ্ট্য | $y^2 = 4ax$ (অনুভূমিক প্রতিসাম্য) | $x^2 = 4ay$ (উল্লম্ব প্রতিসাম্য) |
|---|---|---|
| **শীর্ষবিন্দু (Vertex, $A$)** | $(0, 0)$ | $(0, 0)$ |
| **উপকেন্দ্র (Focus, $S$)** | $(a, 0)$ | $(0, a)$ |
| **অক্ষের সমীকরণ (Axis)** | $y = 0$ ($x$-অক্ষ) | $x = 0$ ($y$-অক্ষ) |
| **শীর্ষে স্পর্শকের সমীকরণ** | $x = 0$ ($y$-অক্ষ) | $y = 0$ ($x$-অক্ষ) |
| **নিয়ামক রেখার সমীকরণ (Directrix)** | $x = -a \iff x + a = 0$ | $y = -a \iff y + a = 0$ |
| **উপকেন্দ্রিক লম্বের দৈর্ঘ্য (Latus Rectum)**| **$4|a|$** | **$4|a|$** |
| **উপকেন্দ্রিক লম্বের সমীকরণ** | $x = a \iff x - a = 0$ | $y = a \iff y - a = 0$ |
| **উপকেন্দ্রিক লম্বের প্রান্তবিন্দুদ্বয়** | $(a, \pm 2a)$ | $(\pm 2a, a)$ |
| **ফোকাল দূরত্ব (Focal Distance, $SP$)** | $SP = |x_1 + a|$ | $SP = |y_1 + a|$ |
| **স্পর্শকের সমীকরণ ($y = mx + c$)** | **$c = \frac{a}{m} \implies y = mx + \frac{a}{m}$** | **$c = -am^2 \implies y = mx - am^2$** |
| **স্পর্শবিন্দুর স্থানাঙ্ক** | $\left(\frac{a}{m^2}, \; \frac{2a}{m}
ight)$ | $(2am, \; am^2)$ |

- **দ্বিঘাত সমীকরণ হতে পরাবৃত্তের শীর্ষবিন্দু নির্ণয়ের ক্যালকুলাস শর্টকাট:**
  - $y$-এর দ্বিঘাত সমীকরণ $Ay^2 + By + Cx + D = 0$ হলে $x$-কে ধ্রুবক ধরে $y$-এর সাপেক্ষে আংশিক অন্তরীকরণ করো:
    $$\frac{\partial}{\partial y} = 0 \implies 2Ay + B = 0 \implies y = -\frac{B}{2A}$$
    অতঃপর $y$-এর মান মূল সমীকরণে বসালেই শীর্ষের $x$-স্থানাঙ্ক বের হয়ে যাবে।
  - $x$-এর দ্বিঘাত সমীকরণে $x$-এর সাপেক্ষে অন্তরীকরণ: $\frac{\partial}{\partial x} = 0$।

### ১.৩ উপবৃত্ত (Ellipse — $0 < e < 1$)
প্রমিত সমীকরণ: $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$

| বৈশিষ্ট্য | $a > b$ (বৃহদাক্ষ $x$-অক্ষ বরাবর) | $b > a$ (বৃহদাক্ষ $y$-অক্ষ বরাবর) |
|---|---|---|
| **কেন্দ্র (Center)** | $(0, 0)$ | $(0, 0)$ |
| **উৎকেন্দ্রিকতা ($e$)** | **$e = \sqrt{1 - \frac{b^2}{a^2}} = \frac{\sqrt{a^2 - b^2}}{a}$** | **$e = \sqrt{1 - \frac{a^2}{b^2}} = \frac{\sqrt{b^2 - a^2}}{b}$** |
| **উপকেন্দ্রদ্বয় (Foci)** | $(\pm ae, 0)$ | $(0, \pm be)$ |
| **শীর্ষবিন্দুদ্বয় (Vertices)** | $(\pm a, 0)$ | $(0, \pm b)$ |
| **বৃহদাক্ষের দৈর্ঘ্য (Major Axis)** | $2a$ (সমীকরণ $y = 0$) | $2b$ (সমীকরণ $x = 0$) |
| **ক্ষুদ্রাক্ষের দৈর্ঘ্য (Minor Axis)** | $2b$ (সমীকরণ $x = 0$) | $2a$ (সমীকরণ $y = 0$) |
| **উপকেন্দ্রিক লম্বের দৈর্ঘ্য** | **$\frac{2b^2}{a}$** | **$\frac{2a^2}{b}$** |
| **নিয়ামক রেখাদ্বয়ের সমীকরণ** | $x = \pm \frac{a}{e}$ | $y = \pm \frac{b}{e}$ |
| **নিয়ামকদ্বয়ের মধ্যবর্তী দূরত্ব** | $\frac{2a}{e}$ | $\frac{2b}{e}$ |
| **উপকেন্দ্রদ্বয়ের মধ্যবর্তী দূরত্ব** | $2ae$ | $2be$ |
| **উপবৃত্তস্থ বিন্দুর ফোকাল দূরত্ব যোগফল**| **$SP + S'P = 2a$ (ধ্রুবক)** | **$SP + S'P = 2b$ (ধ্রুবক)** |
| **স্পর্শকের সমীকরণ ($y = mx + c$)** | **$c^2 = a^2 m^2 + b^2 \implies c = \pm\sqrt{a^2 m^2 + b^2}$** | $c^2 = a^2 m^2 + b^2$ |
| **নিয়ন্ত্রক বৃত্ত (Director Circle)** | **$x^2 + y^2 = a^2 + b^2$** | $x^2 + y^2 = a^2 + b^2$ |
| **উপবৃত্তের আবদ্ধ ক্ষেত্রফল** | **$	ext{Area} = \pi a b$** | $	ext{Area} = \pi a b$ |

### ১.৪ অধিবৃত্ত (Hyperbola — $e > 1$)
প্রমিত সমীকরণ: $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$

| বৈশিষ্ট্য | প্রমিত অধিবৃত্ত ($\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$) | অনুবন্ধী অধিবৃত্ত ($\frac{y^2}{b^2} - \frac{x^2}{a^2} = 1$) |
|---|---|---|
| **কেন্দ্র** | $(0, 0)$ | $(0, 0)$ |
| **উৎকেন্দ্রিকতা ($e$)** | **$e = \sqrt{1 + \frac{b^2}{a^2}} = \frac{\sqrt{a^2 + b^2}}{a}$** | **$e = \sqrt{1 + \frac{a^2}{b^2}} = \frac{\sqrt{a^2 + b^2}}{b}$** |
| **উপকেন্দ্রদ্বয়** | $(\pm ae, 0)$ | $(0, \pm be)$ |
| **শীর্ষবিন্দুদ্বয়** | $(\pm a, 0)$ | $(0, \pm b)$ |
| **আড় অক্ষের দৈর্ঘ্য (Transverse Axis)**| $2a$ (সমীকরণ $y = 0$) | $2b$ (সমীকরণ $x = 0$) |
| **অনুবন্ধী অক্ষের দৈর্ঘ্য (Conjugate Axis)**| $2b$ (সমীকরণ $x = 0$) | $2a$ (সমীকরণ $y = 0$) |
| **উপকেন্দ্রিক লম্বের দৈর্ঘ্য** | **$\frac{2b^2}{a}$** | **$\frac{2a^2}{b}$** |
| **নিয়ামক রেখাদ্বয়ের সমীকরণ** | $x = \pm \frac{a}{e}$ | $y = \pm \frac{b}{e}$ |
| **ফোকাল দূরত্বের বিয়োগফল** | **$|SP - S'P| = 2a$ (ধ্রুবক)** | $|SP - S'P| = 2b$ (ধ্রুবক)** |
| **স্পর্শকের সমীকরণ ($y = mx + c$)** | **$c^2 = a^2 m^2 - b^2 \implies c = \pm\sqrt{a^2 m^2 - b^2}$** | $c^2 = b^2 - a^2 m^2$ |
| **অসীমমুখী রেখা (Asymptotes)** | **$y = \pm \frac{b}{a}x \iff \frac{x^2}{a^2} - \frac{y^2}{b^2} = 0$** | $y = \pm \frac{b}{a}x$ |
| **নিয়ন্ত্রক বৃত্ত (Director Circle)** | **$x^2 + y^2 = a^2 - b^2$ ($a > b$ এর জন্য)** | $x^2 + y^2 = b^2 - a^2$ |

- **অনুবন্ধী অধিবৃত্তের গোল্ডেন আইডেন্টিটি:**
  একটি অধিবৃত্তের উৎকেন্দ্রিকতা $e_1$ এবং তার অনুবন্ধী অধিবৃত্তের উৎকেন্দ্রিকতা $e_2$ হলে:
  $$\frac{1}{e_1^2} + \frac{1}{e_2^2} = 1$$
  - ৩-৪-৫ ট্রিপলেট শর্টকাট: $e_1 = \frac{5}{3} \implies e_2 = \frac{5}{4}$ অথবা $e_1 = \sqrt{2} \implies e_2 = \sqrt{2}$।
- **সমপরাবৃত্ত বা আয়তাকার অধিবৃত্ত ($a = b$):**
  - সমীকরণ: $x^2 - y^2 = a^2$ অথবা অক্ষদ্বয়কে $45^\circ$ ঘোরালে $xy = c^2$।
  - উৎকেন্দ্রিকতা সর্বদা: $e = \sqrt{2}$।
  - অসীমমুখী রেখাদ্বয় পরস্পর লম্ব ($90^\circ$ কোণে ছেদ করে): $y = \pm x$।

### ১.৫ বাস্তব সংখ্যা ও পরমমান অসমতা
- **বাস্তব সংখ্যার সুপ্রিমাম ও ইনফিমাম:**
  - ঊর্ধ্বসীমার মধ্যে ক্ষুদ্রতম মান হলো লঘিষ্ঠ ঊর্ধ্বসীমা বা **সুপ্রিমাম (Supremum / sup)**।
  - নিম্নসীমার মধ্যে বৃহত্তম মান হলো গরিষ্ঠ নিম্নসীমা বা **ইনফিমাম (Infimum / inf)**।
  - সেট $S = \{x \in \mathbb{R} : 2 < x \le 7\} \implies \inf(S) = 2, \; \sup(S) = 7$।
  - সেট $S = \{\frac{1}{n} : n \in \mathbb{N}\} = \{1, 1/2, 1/3, \dots\} \implies \sup(S) = 1, \; \inf(S) = 0$।
- **পরমমান কেন্দ্র-ব্যাসার্ধ সূত্র:**
  $$a < x < b \iff |x - m| < r$$
  যেখানে কেন্দ্র $m = \frac{a+b}{2}$ এবং ব্যাসার্ধ $r = \frac{b-a}{2}$।
- **ভগ্নাংশীয় পরমমান অসমতা ও ডোমেন বর্জন:**
  $$\frac{1}{|ax - b|} \ge k \implies |ax - b| \le \frac{1}{k} \quad (	ext{কিন্তু } ax - b 
eq 0 \implies x 
eq b/a)$$
  - সমাধান ব্যবধি: $\left[\frac{b - 1/k}{a}, \; \frac{b + 1/k}{a}
ight] \setminus \{b/a\}$।

## ২. ৫-সেকেন্ড হ্যান্ড ক্যালকুলেশন হ্যাকস ও কনিক ট্রিপলেট

|---|---|---|
| উপবৃত্তের উৎকেন্দ্রিকতা | $e = \sqrt{1 - \frac{	ext{ছোট হর}}{	ext{বড় হর}}}$ | $\frac{x^2}{25} + \frac{y^2}{16} = 1 \implies e = \sqrt{1 - \frac{16}{25}} = \frac{3}{5} = 0.6$ |
| অধিবৃত্তের উৎকেন্দ্রিকতা | $e = \sqrt{1 + \frac{	ext{ঋণাত্মক হর}}{	ext{ধনাত্মক হর}}}$ | $\frac{x^2}{16} - \frac{y^2}{9} = 1 \implies e = \sqrt{1 + \frac{9}{16}} = \frac{5}{4} = 1.25$ |

| উপবৃত্তের স্পর্শক ধ্রুবক | $c = \pm\sqrt{a^2 m^2 + b^2}$ | $m=1, a=4, b=3 \implies c = \pm\sqrt{16(1)+9} = \pm 5$ |
| অনুবন্ধী অধিবৃত্ত $e_2$ | ৩-৪-৫ পিথাগোরীয় ট্রিপলেট | $e_1 = 5/3 \implies e_2 = 5/4 = 1.25$ |
| সমপরাবৃত্তের $e$ ও কোণ | ফিক্সড মান ধ্রুবক | $e = \sqrt{2} \approx 1.414$, অসীমমুখী কোণ $90^\circ$ |

(b) $1/2$  
(c) $\sqrt{3}/2$  
(d) $1/\sqrt{3}$

**প্রশ্ন:** $y^2 = 4x$ পরাবৃত্ত এবং $y = x$ সরলরেখা দ্বারা প্রথম চতুর্ভাগে আবদ্ধ ক্ষেত্রের ক্ষেত্রফল কত বর্গ একক?  
(a) $8/3$  
(b) $16/3$  
(c) $4/3$  
(d) ৮  

- **সঠিক উত্তর:** (a) $8/3$
- **শর্টকাট ফর্মুলা:** $y^2 = 4ax$ ও $y = mx$ দ্বারা আবদ্ধ ক্ষেত্রফল $= \frac{8a^2}{3m^3}$।
  এখানে $4a = 4 \implies a = 1$ এবং $m = 1$।
  ক্ষেত্রফল $= \frac{8(1)^2}{3(1)^3} = \frac{8}{3}$ বর্গ একক।

## ৫. ইঞ্জিনিয়ারিং টু ঢাবি লিখিত ট্রান্সফার — সেরা ৫টি সমস্যা

### Written 01: উপবৃত্তের ফোকাল দূরত্বের সমষ্টি ধ্রুবক প্রমাণ
**সমস্যা:** প্রমাণ করো যে $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ ($a > b$) উপবৃত্তের ওপর যেকোনো বিন্দু $P(x, y)$ হতে উপকেন্দ্রদ্বয়ের দূরত্বের সমষ্টি বৃহদাক্ষের দৈর্ঘ্যের ($2a$) সমান।
**সমাধান:**
উপকেন্দ্রদ্বয় $S(ae, 0)$ এবং $S'(-ae, 0)$। নিয়ামকদ্বয়ের সমীকরণ $x = \frac{a}{e}$ এবং $x = -\frac{a}{e}$।
কণিকের সংজ্ঞানুসারে:
$SP = e \cdot PM = e \left(\frac{a}{e} - x
ight) = a - ex$
$S'P = e \cdot PM' = e \left(x - \left(-\frac{a}{e}
ight)
ight) = e \left(x + \frac{a}{e}
ight) = a + ex$
উভয় দূরত্ব যোগ করে:
$$SP + S'P = (a - ex) + (a + ex) = 2a \quad 	ext{[প্রমাণিত]}$$

### Written 02: দ্বিঘাত পরাবৃত্তের শীর্ষবিন্দু ও উপকেন্দ্রের পূর্ণ বিশ্লেষণ
**সমস্যা:** $y^2 - 4y - 8x + 20 = 0$ পরাবৃত্তটির শীর্ষবিন্দু, উপকেন্দ্র এবং নিয়ামক রেখার সমীকরণ নির্ণয় করো।
**সমাধান:**
সমীকরণটিকে প্রমিত আকারে সাজিয়ে:
$y^2 - 4y + 4 = 8x - 20 + 4 \implies (y - 2)^2 = 8x - 16 \implies (y - 2)^2 = 8(x - 2)$
ধরি $Y = y - 2, X = x - 2, 4a = 8 \implies a = 2$।
১. শীর্ষবিন্দু ($X = 0, Y = 0$):
$x - 2 = 0 \implies x = 2$; $y - 2 = 0 \implies y = 2$ $\implies$ শীর্ষ $(2, 2)$।
২. উপকেন্দ্র ($X = a, Y = 0$):
$x - 2 = 2 \implies x = 4$; $y - 2 = 0 \implies y = 2$ $\implies$ উপকেন্দ্র $(4, 2)$।
৩. নিয়ামক রেখার সমীকরণ ($X = -a$):
$x - 2 = -2 \implies x = 0$ ($y$-অক্ষ)।

### Written 03: অধিবৃত্তের অসীমমুখী রেখাদ্বয়ের সমীকরণ প্রতিপাদন
**সমস্যা:** প্রমাণ করো যে $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ অধিবৃত্তের অসীমমুখী রেখাদ্বয়ের সমীকরণ $y = \pm \frac{b}{a}x$।
**সমাধান:**
অধিবৃত্তের সমীকরণ হতে $y$ পৃথক করি:
$$\frac{y^2}{b^2} = \frac{x^2}{a^2} - 1 = \frac{x^2}{a^2}\left(1 - \frac{a^2}{x^2}
ight) \implies y = \pm \frac{b}{a}x \sqrt{1 - \frac{a^2}{x^2}}$$
যখন $x 	o \infty$, তখন $\frac{a^2}{x^2} 	o 0$ হয়।
অতএব অসীমে বক্ররেখাটির স্পর্শকের সমীকরণ রূপ নেয়:
$$y = \pm \frac{b}{a}x (1 - 0) \implies y = \pm \frac{b}{a}x \quad 	ext{[প্রমাণিত]}$$

### Written 04: অনুবন্ধী অধিবৃত্তদ্বয়ের উৎকেন্দ্রিকতার সম্পর্ক প্রমাণ
**সমস্যা:** দেখাও যে একটি অধিবৃত্তের উৎকেন্দ্রিকতা $e_1$ এবং তার অনুবন্ধী অধিবৃত্তের উৎকেন্দ্রিকতা $e_2$ হলে $\frac{1}{e_1^2} + \frac{1}{e_2^2} = 1$।
**সমাধান:**
প্রমিত অধিবৃত্ত $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$-এর জন্য:
$$e_1^2 = 1 + \frac{b^2}{a^2} = \frac{a^2 + b^2}{a^2} \implies \frac{1}{e_1^2} = \frac{a^2}{a^2 + b^2}$$
অনুবন্ধী অধিবৃত্ত $\frac{y^2}{b^2} - \frac{x^2}{a^2} = 1$-এর জন্য:
$$e_2^2 = 1 + \frac{a^2}{b^2} = \frac{a^2 + b^2}{b^2} \implies \frac{1}{e_2^2} = \frac{b^2}{a^2 + b^2}$$
উভয় সমীকরণ যোগ করে:
$$\frac{1}{e_1^2} + \frac{1}{e_2^2} = \frac{a^2}{a^2 + b^2} + \frac{b^2}{a^2 + b^2} = \frac{a^2 + b^2}{a^2 + b^2} = 1 \quad 	ext{[প্রমাণিত]}$$

## ৭. আনলিমিটেড অ্যাক্টিভ-রিকল রিপোজিটরি (৪৫টি হাই-ইল্ড ফ্ল্যাশকার্ড)
