## Decisions Taken (1 line each)
- Used `import.meta.glob` lazy JSON chunks in `src/lib/library.ts` so Vite splits each of the 55 bank files into an on-demand chunk while keeping `src/data/bank` as single source of truth.
- Built `src/lib/seo.ts` (`useSEO`) instead of `react-helmet-async` to avoid React 19 peer dependency conflicts and keep initial bundle size minimal.
- Converted `master-set-formula-cards.csv` into `src/data/formulas.json` (366 cards) for lazy-loaded Formula Cards (F9) with print support.
- Renamed `scripts/coverage-scorer.js` to `scripts/coverage-scorer.cjs` because `package.json` uses `"type": "module"`.
