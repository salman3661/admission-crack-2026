#### 1. Physics (P-02: Physical World, Measurement & Newtonian Mechanics)
- **Measurement Errors**:
  - Absolute Error: $\Delta x = |x_{real} - x_{measured}|$
  - Relative Error: $\text{Relative Error} = \frac{\Delta x}{x}$
  - Percentage Error: $\% \text{Error} = \frac{\Delta x}{x} \times 100\%$
  - Power Rule in Propagation: If $Z = A^p B^q / C^r$, then $\frac{\Delta Z}{Z} = p\frac{\Delta A}{A} + q\frac{\Delta B}{B} + r\frac{\Delta C}{C}$
  - Sphere Volume: $V = \frac{4}{3}\pi r^3 \implies \frac{\Delta V}{V} \times 100\% = 3\left(\frac{\Delta r}{r}\times 100\%\right)$
  - Vernier Constant ($VC$) = $\frac{s}{n}$ ($s$ = smallest main scale division, $n$ = vernier divisions)
  - Screw Gauge Least Count ($LC$) = $\frac{\text{Pitch}}{\text{Total circular scale divisions}}$
- **Newtonian Mechanics**:
  - Newton's Second Law: $\vec{F} = \frac{d\vec{p}}{dt} = m\vec{a}$
  - Impulse of Force: $\vec{J} = \int \vec{F} dt = \vec{F}_{avg} \Delta t = \Delta \vec{p} = m\vec{v} - m\vec{u}$
  - Law of Conservation of Linear Momentum: $m_1 \vec{u}_1 + m_2 \vec{u}_2 = m_1 \vec{v}_1 + m_2 \vec{v}_2$
  - Perfectly Inelastic Collision (Combined Velocity): $\vec{V} = \frac{m_1 \vec{u}_1 + m_2 \vec{u}_2}{m_1 + m_2}$
  - Rocket Propulsion:
    - Thrust Force: $F_{thrust} = v_r \left(-\frac{dm}{dt}\right)$
    - Upward Acceleration: $a = \frac{v_r}{m}\left(-\frac{dm}{dt}\right) - g$
    - Condition to take off vertically: $F_{thrust} \ge mg \implies -\frac{dm}{dt} \ge \frac{mg}{v_r}$
  - Apparent Weight in a Lift:
    - Moving up with acceleration $a$: $R = m(g + a)$
    - Moving down with acceleration $a$: $R = m(g - a)$
    - Free fall ($a = g$): $R = m(g - g) = 0$ (Weightlessness)
  - Circular Motion & Banking:
    - Angular velocity $\omega = \frac{d\theta}{dt} = \frac{2\pi}{T} = 2\pi N$
    - Linear vs Angular: $v = \omega r$, $a_c = \frac{v^2}{r} = \omega^2 r$
    - Centripetal Force: $F_c = \frac{mv^2}{r} = m\omega^2 r$
    - Road Banking Angle: $\tan\theta = \frac{v^2}{rg} = \frac{h}{x}$ ($h$ = elevation of outer edge, $x$ = road width)
    - Cyclist Bending: $\tan\theta = \frac{v^2}{rg}$ (with vertical)
  - Moment of Inertia ($I$) & Rotational Dynamics:
    - $I = \sum m_i r_i^2 = \int r^2 dm = M k^2$ ($k$ = radius of gyration)
    - Ring / Thin Hollow Cylinder: $I = MR^2$
    - Uniform Solid Disk / Solid Cylinder: $I = \frac{1}{2}MR^2$
    - Uniform Solid Sphere: $I = \frac{2}{5}MR^2$
    - Thin Spherical Shell (Hollow): $I = \frac{2}{3}MR^2$
    - Thin Uniform Rod (Center): $I = \frac{1}{12}ML^2$; Thin Uniform Rod (End): $I = \frac{1}{3}ML^2$
    - Parallel Axis Theorem: $I = I_G + M d^2$
    - Perpendicular Axis Theorem: $I_z = I_x + I_y$
    - Rotational Kinetic Energy: $E_k = \frac{1}{2}I\omega^2$
    - Rolling Kinetic Energy: $E_{total} = E_{trans} + E_{rot} = \frac{1}{2}mv^2 + \frac{1}{2}I\omega^2 = \frac{1}{2}mv^2\left(1 + \frac{k^2}{R^2}\right)$
    - Angular Momentum: $\vec{L} = \vec{r} \times \vec{p}$, $L = I\omega$
    - Torque: $\vec{\tau} = \vec{r} \times \vec{F} = I\vec{\alpha} = \frac{d\vec{L}}{dt}$

#### 2. Chemistry (C-02: Chemical Change & Environmental Chemistry)
- **Rate of Reaction & Arrhenius Equation**:
  - Rate expression for $aA + bB \to cC + dD$: $\text{Rate} = -\frac{1}{a}\frac{d[A]}{dt} = -\frac{1}{b}\frac{d[B]}{dt} = +\frac{1}{c}\frac{d[C]}{dt} = +\frac{1}{d}\frac{d[D]}{dt}$
  - Rate Law: $\text{Rate} = k [A]^m [B]^n$
  - Arrhenius Equation: $k = A e^{-E_a / RT} \implies \ln k = -\frac{E_a}{RT} + \ln A$
  - Two Temperatures: $\ln\left(\frac{k_2}{k_1}\right) = \frac{E_a}{R}\left(\frac{1}{T_1} - \frac{1}{T_2}\right) = \frac{E_a}{R}\left(\frac{T_2 - T_1}{T_1 T_2}\right)$
- **Chemical Equilibrium ($K_p, K_c$)**:
  - Relation: $K_p = K_c (RT)^{\Delta n}$ where $\Delta n = \sum n_{products}(g) - \sum n_{reactants}(g)$
  - If $\Delta n = 0 \implies K_p = K_c$ (Independent of pressure, e.g., $H_2 + I_2 \rightleftharpoons 2HI$)
  - If $\Delta n > 0 \implies K_p > K_c$ (e.g., $PCl_5 \rightleftharpoons PCl_3 + Cl_2, \Delta n = 1$)
  - If $\Delta n < 0 \implies K_p < K_c$ (e.g., $N_2 + 3H_2 \rightleftharpoons 2NH_3, \Delta n = -2$)
  - Free Energy: $\Delta G^\circ = -RT \ln K$; Spontaneity: $\Delta G = \Delta H - T\Delta S < 0$
  - Green Chemistry 12 Principles: Atom Economy ($\%AE = \frac{\text{Formula weight of desired product}}{\text{Total formula weight of all reactants}} \times 100\%$)
- **Acids, Bases & Buffer Solutions**:
  - Ostwald Dilution Law: For weak acid $HA \rightleftharpoons H^+ + A^-$, $K_a = \frac{\alpha^2 C}{1 - \alpha} \approx \alpha^2 C \implies \alpha = \sqrt{\frac{K_a}{C}}$
  - $[H^+] = c\alpha = \sqrt{K_a C}$; $pH = -\log[H^+] = \frac{1}{2}[pK_a - \log C]$
  - Acidic Buffer (e.g., $CH_3COOH + CH_3COONa$):
    - Henderson-Hasselbalch: $pH = pK_a + \log\frac{[\text{Salt}]}{[\text{Acid}]}$
  - Basic Buffer (e.g., $NH_4OH + NH_4Cl$):
    - $pOH = pK_b + \log\frac{[\text{Salt}]}{[\text{Base}]}$; $pH = 14 - pOH$
- **Gas Laws (Environmental Chemistry)**:
  - Ideal Gas Equation: $PV = nRT = \frac{w}{M}RT \implies P M = \rho R T$
  - Dalton's Law of Partial Pressure: $P_{total} = \sum p_i$; $p_i = X_i P_{total}$ ($X_i$ = mole fraction)
  - Graham's Law of Diffusion: $\frac{r_1}{r_2} = \sqrt{\frac{M_2}{M_1}} = \sqrt{\frac{d_2}{d_1}} = \frac{t_2}{t_1} = \frac{V_1 / t_1}{V_2 / t_2}$
  - RMS Velocity: $c_{rms} = \sqrt{\frac{3RT}{M}} = \sqrt{\frac{3P}{\rho}}$; Average Velocity: $\bar{c} = \sqrt{\frac{8RT}{\pi M}}$; Most Probable: $c_{mp} = \sqrt{\frac{2RT}{M}}$
  - Van der Waals Equation: $\left(P + \frac{a n^2}{V^2}\right)(V - nb) = nRT$

#### 3. Higher Mathematics (HM-02: Circle & Complex Numbers)
- **Circle**:
  - General Equation: $x^2 + y^2 + 2gx + 2fy + c = 0$
  - Center: $(-g, -f)$; Radius: $r = \sqrt{g^2 + f^2 - c}$
  - Intercepts:
    - X-axis intercept: $2\sqrt{g^2 - c}$; Touching X-axis condition: $g^2 = c$
    - Y-axis intercept: $2\sqrt{f^2 - c}$; Touching Y-axis condition: $f^2 = c$
    - Touching both axes: $g^2 = f^2 = c \implies r = |g| = |f|$
  - Tangent Equation at point $(x_1, y_1)$ on circle:
    - $x x_1 + y y_1 + g(x + x_1) + f(y + y_1) + c = 0$
  - Condition of Tangency for line $y = mx + c'$ to circle $x^2 + y^2 = a^2$:
    - $c'^2 = a^2(1 + m^2) \implies c' = \pm a\sqrt{1 + m^2}$
  - Length of Tangent from external point $(x_1, y_1)$:
    - $L = \sqrt{x_1^2 + y_1^2 + 2gx_1 + 2fy_1 + c}$
  - Common Chord of two circles $S_1 = 0$ and $S_2 = 0$:
    - $S_1 - S_2 = 0 \implies 2(g_1 - g_2)x + 2(f_1 - f_2)y + (c_1 - c_2) = 0$
- **Complex Numbers**:
  - Definition: $z = x + iy$, $\bar{z} = x - iy$
  - Modulus: $|z| = r = \sqrt{x^2 + y^2}$; Properties: $|z_1 z_2| = |z_1||z_2|$, $|z_1 / z_2| = |z_1| / |z_2|$
  - Argument: $\theta = \text{Arg}(z)$
    - 1st Quadrant ($x > 0, y > 0$): $\theta = \tan^{-1}|y/x|$
    - 2nd Quadrant ($x < 0, y > 0$): $\theta = \pi - \tan^{-1}|y/x|$
    - 3rd Quadrant ($x < 0, y < 0$): $\theta = -\pi + \tan^{-1}|y/x|$
    - 4th Quadrant ($x > 0, y < 0$): $\theta = -\tan^{-1}|y/x|$
  - Polar & Euler Form: $z = r(\cos\theta + i\sin\theta) = r e^{i\theta}$
  - De Moivre's Theorem: $(\cos\theta + i\sin\theta)^n = \cos(n\theta) + i\sin(n\theta)$
  - Cube Roots of Unity: $1, \omega, \omega^2$ where $\omega = \frac{-1 + \sqrt{3}i}{2}, \omega^2 = \frac{-1 - \sqrt{3}i}{2}$
    - $1 + \omega + \omega^2 = 0$, $\omega^3 = 1$, $\omega^{3n} = 1$, $\omega^{3n+1} = \omega$, $\omega^{3n+2} = \omega^2$
  - Square Root of $a + ib$: $\pm\left(\sqrt{\frac{|z|+a}{2}} + i \operatorname{sgn}(b)\sqrt{\frac{|z|-a}{2}}\right)$
    - Square root of $i$: $\pm\frac{1}{\sqrt{2}}(1 + i)$; Square root of $-i$: $\pm\frac{1}{\sqrt{2}}(1 - i)$

#### 4. Biology (Bio-02: Animal Diversity & Introduction to Animals)
- **Hydra (Hydra vulgaris)**:
  - Phylum: Cnidaria, Class: Hydrozoa, Order: Hydroida, Genus: Hydra
  - Body Wall Layers: Epidermis (Ectoderm derived) and Gastrodermis (Endoderm derived) separated by Mesoglea (Acellular jelly-like layer)
  - Epidermal Cells (7 types): Epitheliomuscular, Interstitial (Totipotent - regeneration), Cnidocyte (Defense, prey capture), Sensory, Nerve, Glandular, Germ cells
  - Nematocysts (4 types):
    - Stenotele / Penetrant: Largest, pear-shaped, shaft with 3 barbs and spirals of barbulets, injects toxic Hypnotoxin (Protein + Phenol)
    - Volvent / Desmoneme: Small, pear-shaped, unarmed thread tightly coils around prey bristles
    - Streptoline glutinant / Holotrichous: Oval, thread with spines throughout, secretes sticky fluid
    - Stereoline glutinant / Atrichous: Smallest, smooth spineless thread, secretes sticky fluid for locomotion
  - Locomotion: Looping (Somersaulting for rapid movement), Gliding (on basal disc), Floating, Climbing, Swimming
  - Symbiosis: Zoochlorella algae inside gastrodermal cells of Chlorohydra viridissima
- **Grasshopper (Poekilocerus pictus)**:
  - Phylum: Arthropoda, Class: Insecta, Order: Orthoptera
  - Body division: Head (Hypognathous), Thorax (Pro, Meso, Meta), Abdomen (11 segments)
  - Mouthparts (Mandibulate / Chewing type): Labrum (Upper lip), Mandibles (Jaws with teeth), Maxillae (with 5-segmented palp), Labium (Lower lip with 3-segmented palp), Hypopharynx (Tongue)
  - Compound Eye: Ommatidia (units of vision); Apposition / Mosaic image in bright light; Superposition image in dim light
  - Blood vascular system: Open type; Haemolymph (colorless plasma + amoeboid haemocytes), Tubular heart (7 chambers with ostia), Alary muscles (12 pairs)
  - Respiratory system: Tracheal system; Spiracles (10 pairs: 2 thoracic, 8 abdominal)
  - Excretion: Malpighian tubules (open into junction of midgut and hindgut; excrete uric acid crystals)
- **Rui Fish (Labeo rohita)**:
  - Phylum: Chordata, Class: Actinopterygii, Order: Cypriniformes, Family: Cyprinidae
  - Scales: Cycloid (concentric lines of growth / annuli determine age)
  - Circulatory System: Single circuit, Venous heart (contains only deoxygenated $CO_2$-rich blood)
  - Heart chambers: Sinus venosus (accessory), Atrium, Ventricle, Bulbus arteriosus (accessory cone)
  - Afferent branchial arteries (4 pairs carrying deoxygenated blood to gills); Efferent branchial arteries (4 pairs collecting oxygenated blood)
  - Swim Bladder (Air Bladder / Patka): Hydrostatic organ, physostomous (connected to esophagus via pneumatic duct), contains gas gland (secreting $O_2, N_2, CO_2$) and rete mirabile

#### 5. English (E-02: Grammar, Usage & Vocabulary)
- **Pronouns & Antecedent Rules**:
  - Personal, Demonstrative, Relative, Interrogative, Reflexive, Indefinite, Distributive, Reciprocal
  - Rule of 231 (Second person, Third person, First person) for positive sentences; Rule of 123 for confessions / negative acts
  - Case agreement: Subjective case after 'than'/'as' when comparing subjects; Objective case after prepositions and transitive verbs
- **Voice Change Architecture**:
  - Transitive vs Intransitive verbs; Quasi-passive verbs (e.g., "Honey tastes sweet" $\to$ "Honey is sweet when it is tasted")
  - Imperative passive: "Do it" $\to$ "Let it be done"; "Never tell a lie" $\to$ "Let never a lie be told"
  - Complex sentences: "People say that honesty is the best policy" $\to$ "It is said that honesty is the best policy"
- **Tag Questions**:
  - Positive statement $\to$ Negative tag; Negative statement $\to$ Positive tag
  - Imperative requests: "Pass the salt, will you / won't you?"; "Let's go" $\to$ "shall we?"; "Let them go" $\to$ "will you?"
- **Redundancy & Wordiness Rules**:
  - Eliminating duplicate meanings: "return back" $\to$ "return"; "discuss about" $\to$ "discuss"; "true fact" $\to$ "fact"; "final conclusion" $\to$ "conclusion"
- **Master Vocabulary, Idioms & Prepositions (Letters D-F)**:
  - Appropriate Prepositions: Abide by, Abound in/with, Adjacent to, Absorbed in, Deficient in, Devoid of, Eligible for, Famous for

[Ans: $\sqrt{c(g^2 + f^2 - c)}$]  
Solve: বৃত্তের ব্যাসার্ধ $r = \sqrt{g^2 + f^2 - c}$; মূলবিন্দু হতে স্পর্শকের দৈর্ঘ্য $d = \sqrt{0 + 0 + c} = \sqrt{c}$  
চতুর্ভুজ $OACB = 2 \times \Delta OAC = 2 \times \frac{1}{2} \times AC \times OA = r \times d = \sqrt{c(g^2 + f^2 - c)}$

**[SRC: ENGG_EXTRA] Q11.** x-অক্ষকে স্পর্শ করে এমন একটি বৃত্তের কেন্দ্র $(4, 5)$ হলে, বৃত্তটি দ্বারা y-অক্ষ হতে খণ্ডিত অংশের দৈর্ঘ্য কত?
