#### ১. ওয়ান-স্টপ মাস্টার হ্যান্ডনোট (Complete Core Digest)

##### ১.১ বৃত্ত (Circle — ১ম পত্র: অধ্যায় ০৪)

###### (ক) বৃত্তের আদর্শ ও সাধারণ সমীকরণ এবং বৈশিষ্ট্য
১. **কেন্দ্র $(0, 0)$ এবং ব্যাসার্ধ $r$:** $x^2 + y^2 = r^2$।
২. **কেন্দ্র $(h, k)$ এবং ব্যাসার্ধ $r$ (প্রমিত সমীকরণ):** $(x - h)^2 + (y - k)^2 = r^2$।
৩. **সাধারণ সমীকরণ:** $x^2 + y^2 + 2gx + 2fy + c = 0$।
   - **কেন্দ্র:** $C(-g, -f) = \left(-\frac{x\text{-এর সহগ}}{2}, -\frac{y\text{-এর সহগ}}{2}\right)$। *(সতর্কতা: আগে $x^2$ ও $y^2$-এর সহগকে $1$ করে নিতে হবে!)*
   - **ব্যাসার্ধ:** $r = \sqrt{g^2 + f^2 - c}$। (বাস্তব বৃত্তের শর্ত: $g^2 + f^2 - c > 0$; বিন্দুবৃত্ত হলে $g^2 + f^2 - c = 0$)।
৪. **দ্বিঘাত সমীকরণ $ax^2 + by^2 + 2hxy + 2gx + 2fy + c = 0$ বৃত্ত হওয়ার ৩টি শর্ত:**
   - (১) $x^2$ ও $y^2$-এর সহগ সমান ও অশূন্য হতে হবে ($a = b \neq 0$)।
   - (২) $xy$ সংবলিত কোনো পদ থাকবে না ($h = 0$)।
   - (৩) $g^2 + f^2 - ac \ge 0$ (ভাগ করার পর)।
৫. **ব্যাসের প্রান্তবিন্দু $(x_1, y_1)$ ও $(x_2, y_2)$ দেওয়া থাকলে বৃত্তের সমীকরণ:**
   $$(x - x_1)(x - x_2) + (y - y_1)(y - y_2) = 0$$
৬. **পোলার স্থানাঙ্কে বৃত্তের সমীকরণ:**
   - $x = r\cos\theta, y = r\sin\theta$ এবং $x^2 + y^2 = r^2$ বসিয়ে:
     $$r^2 + 2r(g\cos\theta + f\sin\theta) + c = 0$$
   - কেন্দ্র $(r_1, \theta_1)$ এবং ব্যাসার্ধ $a$ হলে: $r^2 - 2rr_1\cos(\theta - \theta_1) + r_1^2 - a^2 = 0$।
   - বিশেষ পোলার বৃত্ত: $r = 2a\cos\theta$ $\to$ কেন্দ্র $(a, 0)$, ব্যাসার্ধ $a$; $r = 2a\sin\theta$ $\to$ কেন্দ্র $(0, a)$, ব্যাসার্ধ $a$।

###### (খ) অক্ষদ্বয়ের খণ্ডিতাংশ ও অক্ষ স্পর্শ করার শর্ত — মাস্টার চার্ট
| শর্ত / বৈশিষ্ট্য | গাণিতিক সূত্র ($x^2+y^2+2gx+2fy+c=0$) | কেন্দ্র $(h, k)$ ও ব্যাসার্ধ $r$ আকারে |
|---|---|---|
| **$x$-অক্ষের খণ্ডিতাংশের দৈর্ঘ্য** | $2\sqrt{g^2 - c}$ | $2\sqrt{r^2 - k^2}$ |
| **$y$-অক্ষের খণ্ডিতাংশের দৈর্ঘ্য** | $2\sqrt{f^2 - c}$ | $2\sqrt{r^2 - h^2}$ |
| **$x$-অক্ষকে স্পর্শ করলে** | $g^2 = c$; স্পর্শবিন্দু $(-g, 0)$ | $r = |k|$ = $|\text{কেন্দ্রের কোটি}|$ |
| **$y$-অক্ষকে স্পর্শ করলে** | $f^2 = c$; স্পর্শবিন্দু $(0, -f)$ | $r = |h|$ = $|\text{কেন্দ্রের ভুজ}|$ |
| **উভয় অক্ষকে স্পর্শ করলে** | $g^2 = f^2 = c$ | $r = |h| = |k|$; কেন্দ্র $(\pm r, \pm r)$ |
| **মূলবিন্দুগামী বৃত্ত হলে** | $c = 0 \implies x^2 + y^2 + 2gx + 2fy = 0$ | $h^2 + k^2 = r^2$ |
| **মূলবিন্দুগামী এবং অক্ষদ্বয় হতে $a$ ও $b$ অংশ ছেদ করলে** | $x^2 + y^2 - ax - by = 0$ | কেন্দ্র $\left(\frac{a}{2}, \frac{b}{2}\right)$, ব্যাসার্ধ $\frac{1}{2}\sqrt{a^2+b^2}$ |
| **কেন্দ্র $x$-অক্ষের ওপর অবস্থিত হলে** | $f = 0$ (অর্থাৎ $y$-এর সহগ শূন্য) | $k = 0 \implies$ কেন্দ্র $(-g, 0)$ |
| **কেন্দ্র $y$-অক্ষের ওপর অবস্থিত হলে** | $g = 0$ (অর্থাৎ $x$-এর সহগ শূন্য) | $h = 0 \implies$ কেন্দ্র $(0, -f)$ |

###### (গ) বিন্দুর অবস্থান, স্পর্শক, জ্যা এবং দুই বৃত্তের সম্পর্ক
১. **বৃত্তের সাপেক্ষে $(x_1, y_1)$ বিন্দুর অবস্থান:**
   - $S_1 = x_1^2 + y_1^2 + 2gx_1 + 2fy_1 + c$ নির্ণয় করো:
     - $S_1 > 0 \implies$ বিন্দুটি বৃত্তের **বাইরে**।
     - $S_1 = 0 \implies$ বিন্দুটি বৃত্তের **ওপরে**।
     - $S_1 < 0 \implies$ বিন্দুটি বৃত্তের **ভেতরে**।
2. **স্পর্শকের সমীকরণ ও দৈর্ঘ্য:**
   - বৃত্তের ওপরস্থ $(x_1, y_1)$ বিন্দুতে স্পর্শকের সমীকরণ (**প্রতিস্থাপন নিয়ম**):
     - $x^2 \to xx_1$, $y^2 \to yy_1$, $2x \to (x + x_1)$, $2y \to (y + y_1)$।
     - অর্থাৎ: $xx_1 + yy_1 + g(x + x_1) + f(y + y_1) + c = 0$। (এবং $x^2 + y^2 = r^2$-এ: $xx_1 + yy_1 = r^2$)।
   - **বহিঃস্থ $(x_1, y_1)$ বিন্দু হতে অঙ্কিত স্পর্শকের দৈর্ঘ্য:**
     $$L = \sqrt{S_1} = \sqrt{x_1^2 + y_1^2 + 2gx_1 + 2fy_1 + c}$$
   - **সরলরেখা $ax + by + k = 0$ বৃত্তকে স্পর্শ করার শর্ত:**
     $$\text{কেন্দ্র হতে রেখার লম্ব দূরত্ব } (d) = \text{ব্যাসার্ধ } (r) \implies \frac{|ah + bk + c'|}{\sqrt{a^2 + b^2}} = r$$
   - $y = mx + c$ রেখা $x^2 + y^2 = r^2$ বৃত্তকে স্পর্শ করলে: $c = \pm r\sqrt{1 + m^2}$।
৩. **জ্যা-এর দৈর্ঘ্য ও সমীকরণ:**
   - কেন্দ্র থেকে জ্যা-এর লম্ব দূরত্ব $d$ হলে **জ্যা-এর দৈর্ঘ্য** $= 2\sqrt{r^2 - d^2}$।
   - জ্যা কেন্দ্রে $\theta$ কোণ উৎপন্ন করলে জ্যা-এর দৈর্ঘ্য $= 2r\sin\left(\frac{\theta}{2}\right)$। (**বিশেষ:** $\theta = 60^\circ$ হলে সমবাহু ত্রিভুজ গঠিত হয় এবং জ্যা-এর দৈর্ঘ্য $= r$!)
   - $(x_1, y_1)$ বিন্দুতে সমদ্বিখণ্ডিত জ্যা-এর সমীকরণ: $T = S_1$।
৪. **দুটি বৃত্তের সাধারণ জ্যা ও পরস্পরকে স্পর্শ করার শর্ত:**
   - **সাধারণ জ্যা (Common Chord):** $S_1 - S_2 = 0 \implies 2(g_1 - g_2)x + 2(f_1 - f_2)y + (c_1 - c_2) = 0$।
   - দুটি বৃত্তের কেন্দ্রদ্বয়ের দূরত্ব $d = C_1 C_2$ এবং ব্যাসার্ধ $r_1, r_2$ ($r_1 > r_2$) হলে:

| শর্ত | জ্যামিতিক অবস্থা | সাধারণ স্পর্শকের সংখ্যা | স্পর্শবিন্দু বিভাজন অনুপাত |
|---|---|---|---|
| $d > r_1 + r_2$ | বৃত্তদ্বয় পরস্পর **পৃথক** (বাইরে অবস্থিত) | **৪টি** (২টি সরল, ২টি তির্যক) | — |
| $d = r_1 + r_2$ | পরস্পরকে **বহিঃস্থভাবে স্পর্শ** করে | **৩টি** | $r_1 : r_2$ অনুপাতে **অন্তর্বিভক্ত** করে |
| $r_1 - r_2 < d < r_1 + r_2$ | পরস্পরকে **ছেদ** করে | **২টি** | — |
| $d = |r_1 - r_2|$ | পরস্পরকে **অন্তঃস্থভাবে স্পর্শ** করে | **১টি** | $r_1 : r_2$ অনুপাতে **বহির্বিভক্ত** করে |
| $d < |r_1 - r_2|$ | একটি অপরটির **ভেতরে** অবস্থিত (স্পর্শহীন) | **০টি** | — |

   - **দুটি বৃত্ত লম্বভাবে (Orthogonally) ছেদ করার শর্ত:** $2g_1 g_2 + 2f_1 f_2 = c_1 + c_2$ (অর্থাৎ $d^2 = r_1^2 + r_2^2$)।

##### ১.২ ত্রিকোণমিতি ও সংযুক্ত কোণের ত্রিকোণমিতিক অনুপাত (Trigonometry & Associated Angles)

###### (ক) চতুর্ভাগ নিয়ম (ASTC) ও সংযুক্ত কোণ $(n \cdot 90^\circ \pm \theta)$
১. **চতুর্ভাগ চিহ্ন:** ১ম চতুর্ভাগে $(0^\circ - 90^\circ)$ All ধনাত্মক; ২য় চতুর্ভাগে $(90^\circ - 180^\circ)$ $\sin, \csc$ ধনাত্মক; ৩য় চতুর্ভাগে $(180^\circ - 270^\circ)$ $\tan, \cot$ ধনাত্মক; ৪র্থ চতুর্ভাগে $(270^\circ - 360^\circ)$ $\cos, \sec$ ধনাত্মক।
২. **রূপান্তর নিয়ম:**
   - $n$ **জোড়** হলে অনুপাত অপরিবর্তিত থাকে ($\sin \leftrightarrow \sin, \cos \leftrightarrow \cos, \tan \leftrightarrow \tan$)।
   - $n$ **বিজোড়** হলে সহ-অনুপাতে পরিবর্তিত হয় ($\sin \leftrightarrow \cos, \tan \leftrightarrow \cot, \sec \leftrightarrow \csc$)।
৩. **মৌলিক অভেদ ও অন্যন্যক সম্পর্ক (খুবই গুরুত্বপূর্ণ শর্টকাট!):**
   - $\sec^2\theta - \tan^2\theta = 1 \implies (\sec\theta + \tan\theta)(\sec\theta - \tan\theta) = 1$।
     - তাই **$\sec\theta + \tan\theta = k$ হলে $\sec\theta - \tan\theta = \frac{1}{k}$** এবং যোগ করে **$\sec\theta = \frac{1}{2}\left(k + \frac{1}{k}\right), \tan\theta = \frac{1}{2}\left(k - \frac{1}{k}\right), \sin\theta = \frac{k^2 - 1}{k^2 + 1}$**!
   - একইভাবে **$\csc\theta + \cot\theta = k$ হলে $\csc\theta - \cot\theta = \frac{1}{k}$**।
   - যদি **$\sin\theta + \cos\theta = x$** হয়, তবে **$\sin\theta\cos\theta = \frac{x^2 - 1}{2}$** এবং **$\sin\theta - \cos\theta = \pm\sqrt{2 - x^2}$**।

###### (খ) ত্রিকোণমিতিক ধারার যোগফল (Series Shortcuts)
১. **$\sin^2\theta$ বা $\cos^2\theta$ ধারার যোগফল:**
   - যদি দুটি কোণের যোগফল $\alpha + \beta = 90^\circ$ হয়, তবে $\sin^2\alpha + \sin^2\beta = \sin^2\alpha + \cos^2\alpha = 1$ (এবং $\cos^2\alpha + \cos^2\beta = 1$)।
   - পদসংখ্যা $N = \frac{\text{শেষ কোণ} - \text{প্রথম কোণ}}{\text{সাধারণ অন্তর}} + 1$।
   - যদি ধারাটি $0^\circ$ থেকে $90^\circ$-এর মধ্যে প্রতিসম হয়, তবে যোগফল $= \frac{\text{পদসংখ্যা}}{2}$ (যদি শেষে $\sin^2 90^\circ = 1$ অতিরিক্ত থাকে তবে $+1$ যোগ হবে)।
2. **$\tan\theta$ ধারার গুণফল:**
   - $\alpha + \beta = 90^\circ$ হলে $\tan\alpha \cdot \tan\beta = 1$ (যেমন: $\tan 1^\circ \cdot \tan 2^\circ \cdots \tan 89^\circ = 1$)।

###### (গ) যৌগিক কোণ, গুণিতক কোণ ও চরম মান (Compound & Multiple Angles)
১. **যৌগিক কোণের গোল্ডেন সূত্রসমূহ:**
   - $\sin(A \pm B) = \sin A\cos B \pm \cos A\sin B$
   - $\cos(A \pm B) = \cos A\cos B \mp \sin A\sin B$
   - $\tan(A \pm B) = \frac{\tan A \pm \tan B}{1 \mp \tan A\tan B}$
   - $\sin(A + B)\sin(A - B) = \sin^2 A - \sin^2 B = \cos^2 B - \cos^2 A$
   - $\cos(A + B)\cos(A - B) = \cos^2 A - \sin^2 B$
   - **বিশেষ অভেদ-১:** $A + B = 45^\circ$ (বা $\frac{\pi}{4}$) হলে **$(1 + \tan A)(1 + \tan B) = 2$** এবং $\tan A + \tan B + \tan A\tan B = 1$।
   - **বিশেষ অভেদ-২:** $\frac{\cos\theta + \sin\theta}{\cos\theta - \sin\theta} = \frac{1 + \tan\theta}{1 - \tan\theta} = \tan(45^\circ + \theta)$।
২. **গুণিতক ও উপগুণিতক কোণের ম্যাজিক সূত্র:**
   - $\sin 2A = 2\sin A\cos A = \frac{2\tan A}{1 + \tan^2 A}$
   - $\cos 2A = \cos^2 A - \sin^2 A = 2\cos^2 A - 1 = 1 - 2\sin^2 A = \frac{1 - \tan^2 A}{1 + \tan^2 A}$
   - **স্বর্ণসূত্র (ক্যালকুলাস ও ত্রিকোণমিতিতে সর্বাধিক ব্যবহৃত!):**
     $$1 + \cos 2A = 2\cos^2 A, \quad 1 - \cos 2A = 2\sin^2 A, \quad \frac{1 - \cos 2A}{1 + \cos 2A} = \tan^2 A$$
     $$\frac{1 - \cos 2A}{\sin 2A} = \tan A, \quad \frac{1 + \cos 2A}{\sin 2A} = \cot A$$
   - **৬০° কোণের ত্রয়ী গুণফল:**
     $$\sin\theta \cdot \sin(60^\circ - \theta) \cdot \sin(60^\circ + \theta) = \frac{1}{4}\sin 3\theta$$
     $$\cos\theta \cdot \cos(60^\circ - \theta) \cdot \cos(60^\circ + \theta) = \frac{1}{4}\cos 3\theta$$
     $$\tan\theta \cdot \tan(60^\circ - \theta) \cdot \tan(60^\circ + \theta) = \tan 3\theta$$
৩. **$f(\theta) = a\cos\theta + b\sin\theta + c$ রাশির সর্বোচ্চ ও সর্বনিম্ন মান:**
   - **সর্বোচ্চ মান (Maximum):** $c + \sqrt{a^2 + b^2}$।
   - **সর্বনিম্ন মান (Minimum):** $c - \sqrt{a^2 + b^2}$।
৪. **ত্রিভুজের গুণাবলি ($\triangle ABC$-তে $A + B + C = 180^\circ$):**
   - **সাইন সূত্র:** $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$ (যেখানে $R =$ পরিব্যাসার্ধ)।
   - **কোসাইন সূত্র:** $\cos A = \frac{b^2 + c^2 - a^2}{2bc}$; $\cos B = \frac{c^2 + a^2 - b^2}{2ca}$; $\cos C = \frac{a^2 + b^2 - c^2}{2ab}$।
   - **বিশেষ শর্টকাট:** যদি একটি ত্রিভুজের বাহুগুলো $a, b$ এবং $\sqrt{a^2 + ab + b^2}$ হয়, তবে বৃহত্তম কোণটি সর্বদা **$120^\circ$**!
   - $A + B + C = \pi$ হলে: $\tan A + \tan B + \tan C = \tan A\tan B\tan C$।

##### ১.৩ জটিল সংখ্যা (Complex Numbers — ২য় পত্র: অধ্যায় ০৩)

###### (ক) কাল্পনিক একক $i$-এর ঘাত ও ধর্ম
১. $i = \sqrt{-1}, \quad i^2 = -1, \quad i^3 = -i, \quad i^4 = 1, \quad \frac{1}{i} = -i$।
২. যেকোনো ঘাত $i^n$ নির্ণয়ে $n$-কে $4$ দিয়ে ভাগ করে ভাগশেষ $r$ নিলে $i^n = i^r$। (ঋণাত্মক ঘাত হলে: $i^{-35} = \frac{1}{i^{35}} = \frac{i^{36}}{i^{35}} = i^1 = i$)।
৩. **$i$-এর যেকোনো ৪টি ক্রমিক ঘাতের যোগফল সর্বদা শূন্য:**
   $$i^n + i^{n+1} + i^{n+2} + i^{n+3} = 0$$
৪. গুরুত্ত্বপূর্ণ মান: $(1 + i)^2 = 2i$, $(1 - i)^2 = -2i$, $\frac{1 + i}{1 - i} = i$, $\frac{1 - i}{1 + i} = -i$।

###### (খ) মডুলাস, মুখ্য আর্গুমেন্ট, পোলার আকার ও অনুবন্ধী জটিল সংখ্যা
১. $z = x + iy$ হলে অনুবন্ধী জটিল সংখ্যা $\bar{z} = x - iy$।
   - $z + \bar{z} = 2x$ (বাস্তব); $z - \bar{z} = 2iy$ (কাল্পনিক); $z\bar{z} = x^2 + y^2 = |z|^2$ (বাস্তব)।
২. **মডুলাস:** $r = |z| = \sqrt{x^2 + y^2}$। (গুণ ও ভাগে: $|z_1 z_2| = |z_1||z_2|$ এবং $\left|\frac{z_1}{z_2}\right| = \frac{|z_1|}{|z_2|}$)।
৩. **মুখ্য আর্গুমেন্ট ($\theta = \text{arg}(z)$, যেখানে $-\pi < \theta \le \pi$):**
   - প্রথমে সূক্ষ্মকোণ $\alpha = \tan^{-1}\left|\frac{y}{x}\right|$ বের করো, তারপর চতুর্ভাগ অনুযায়ী:

| চতুর্ভাগ | $(x, y)$-এর চিহ্ন | মুখ্য আর্গুমেন্ট ($\theta$) | সাধারণ আর্গুমেন্ট ($0 \le \theta < 2\pi$ হলে) |
|---|---|---|---|
| **১ম চতুর্ভাগ** | $(+, +)$ | $\theta = \alpha$ | $\alpha$ |
| **২য় চতুর্ভাগ** | $(-, +)$ | $\theta = \pi - \alpha$ | $\pi - \alpha$ |
| **৩য় চতুর্ভাগ** | $(-, -)$ | $\theta = -\pi + \alpha = -(\pi - \alpha)$ | $\pi + \alpha$ |
| **৪র্থ চতুর্ভাগ** | $(+, -)$ | $\theta = -\alpha$ | $2\pi - \alpha$ |

   - **অক্ষের ওপর অবস্থিত সংখ্যার আর্গুমেন্ট:**
     - ধনাত্মক বাস্তব ($x > 0$, যেমন $5$): $\theta = 0$।
     - ঋণাত্মক বাস্তব ($x < 0$, যেমন $-5$): $\theta = \pi$।
     - ধনাত্মক কাল্পনিক ($iy, y > 0$, যেমন $3i$): $\theta = \frac{\pi}{2}$।
     - ঋণাত্মক কাল্পনিক ($-iy, y > 0$, যেমন $-3i$): $\theta = -\frac{\pi}{2}$।
   - আর্গুমেন্টের লগারিদমিক ধর্ম: $\text{arg}(z_1 z_2) = \text{arg}(z_1) + \text{arg}(z_2)$ এবং $\text{arg}\left(\frac{z_1}{z_2}\right) = \text{arg}(z_1) - \text{arg}(z_2)$।
৪. **পোলার ও অয়লার আকার:** $z = r(\cos\theta + i\sin\theta) = r e^{i\theta}$।

###### (গ) জটিল সংখ্যার বর্গমূল ও এককের ঘনমূল ($\omega$)
১. **বর্গমূলের সূত্র ও রেডিমেড মান:**
   $$\sqrt{a \pm ib} = \pm\left(\sqrt{\frac{r + a}{2}} \pm i\sqrt{\frac{r - a}{2}}\right) \quad \left[\text{যেখানে } r = \sqrt{a^2 + b^2}\right]$$
   - **মুখস্থ রেডিমেড মান (পরীক্ষায় সরাসরি আসে!):**
     - $\sqrt{2i} = \pm(1 + i)$ এবং $\sqrt{-2i} = \pm(1 - i)$।
     - $\sqrt{i} = \pm\frac{1}{\sqrt{2}}(1 + i)$ এবং $\sqrt{-i} = \pm\frac{1}{\sqrt{2}}(1 - i)$।
     - $\sqrt{i} + \sqrt{-i} = \pm\sqrt{2}$।
2. **এককের ঘনমূল ($\sqrt[3]{1}$):**
   - মূল তিনটি: $1, \omega, \omega^2$, যেখানে:
     $$\omega = \frac{-1 + \sqrt{3}i}{2}, \qquad \omega^2 = \frac{-1 - \sqrt{3}i}{2}$$
   - **মৌলিক ধর্মসমূহ:**
     - (১) $\omega^3 = 1$ (তাই $\omega^n$-এ ঘাতকে $3$ দিয়ে ভাগ করে ভাগশেষ নিতে হয়)।
     - (২) **$1 + \omega + \omega^2 = 0$** $\implies 1 + \omega = -\omega^2$, $1 + \omega^2 = -\omega$, $\omega + \omega^2 = -1$।
     - (৩) জটিল ঘনমূল দুটির গুণফল $= \omega \cdot \omega^2 = \omega^3 = 1$ এবং যোগফল $= \omega + \omega^2 = -1$।
     - (৪) গুরুত্বপূর্ণ উৎপাদক: $a^2 - ab + b^2 = (a + b\omega)(a + b\omega^2)$ এবং $a^2 + ab + b^2 = (a - b\omega)(a - b\omega^2)$।

###### (ঘ) জটিল সমতলে সঞ্চারপথ (Locus in Complex Plane)
ধরি $z = x + iy$:
১. $|z - a| = r \implies$ **বৃত্ত** (কেন্দ্র $a$, ব্যাসার্ধ $r$; যেমন $|z - 3 + 4i| = 5 \implies$ কেন্দ্র $(3, -4)$, ব্যাসার্ধ $5$)।
২. $|z - z_1| = |z - z_2| \implies$ **$z_1$ ও $z_2$ বিন্দুদ্বয়ের সংযোজক রেখাংশের লম্বদ্বিখণ্ডক (সরলরেখা)**।
৩. $\left|\frac{z - z_1}{z - z_2}\right| = k$: যদি $k = 1$ হয় তবে **সরলরেখা**; যদি $k \neq 1$ হয় তবে **বৃত্ত** (অ্যাপোলোনিয়াসের বৃত্ত)।
৪. $|z - z_1| + |z - z_2| = 2a$: যদি $2a > |z_1 - z_2|$ হয় তবে **উপবৃত্ত** (Ellipse)।
৫. $||z - z_1| - |z - z_2|| = 2a$: যদি $2a < |z_1 - z_2|$ হয় তবে **অধিবৃত্ত** (Hyperbola)।

#### ২. ক্যালকুলেটর ছাড়া Hand Calculation হ্যাকস ও মেমোরি ছন্দ

##### ২.১ ক্যালকুলেটর ছাড়া ৫ সেকেন্ডে হায়ার ম্যাথ হ্যাকস
১. **৫ সেকেন্ডে জটিল সংখ্যার বর্গমূল নির্ণয়ের হ্যাক ($\sqrt{a \pm ib}$):**
   - **ধাপ ১:** কাল্পনিক অংশের সহগ $b$-কে **$2$ দিয়ে ভাগ** করো ($\frac{b}{2}$)।
   - **ধাপ ২:** $\frac{b}{2}$-কে এমন দুটি উৎপাদকে ভাঙো ($p \times q = \frac{b}{2}$) যাতে **তাদের বর্গের অন্তর বাস্তব অংশ $a$-এর সমান হয়** ($p^2 - q^2 = a$)।
   - **ধাপ ৩:** তাহলে বর্গমূল হবে সরাসরি $\mathbf{\pm(p \pm iq)}$!
   - **উদাহরণ ১:** $\sqrt{-8 - 6\sqrt{-1}} = \sqrt{-8 - 6i}$ নির্ণয় করো।
     - কাল্পনিক অংশকে $2$ দিয়ে ভাগ: $\frac{6}{2} = 3 = 1 \times 3$।
     - বর্গের অন্তর: $1^2 - 3^2 = 1 - 9 = -8$ (বাস্তব অংশের সাথে মিলে গেছে!)।
     - তাই উত্তর সরাসরি: $\mathbf{\pm(1 - 3i)}$! (সময় লাগলো ৩ সেকেন্ড!)
   - **উদাহরণ ২:** $\sqrt{7 - 24i}$ নির্ণয় করো।
     - $\frac{24}{2} = 12 = 4 \times 3$ এবং $4^2 - 3^2 = 16 - 9 = 7$।
     - তাই উত্তর সরাসরি: $\mathbf{\pm(4 - 3i)}$!
   - **উদাহরণ ৩:** $\sqrt{5 + 12i} \implies \frac{12}{2} = 6 = 3 \times 2$ এবং $3^2 - 2^2 = 5 \implies \mathbf{\pm(3 + 2i)}$!
২. **এককের ঘনমূল $\omega$-এর যেকোনো বড় ঘাত শর্টকাট:**
   - সংখ্যার অঙ্কগুলোর যোগফলকে $3$ দিয়ে ভাগ করো!
   - যেমন: $\omega^{2026} \implies 2 + 0 + 2 + 6 = 10 \implies 10$-কে $3$ দিয়ে ভাগ করলে ভাগশেষ $1 \implies \omega^{2026} = \omega^1 = \omega$!
   - যেমন: $(1 - \omega + \omega^2)^n + (1 + \omega - \omega^2)^n = (-2\omega)^n + (-2\omega^2)^n = (-2)^n(\omega^n + \omega^{2n})$।
     - যদি $n$ সংখ্যাটি $3$ দ্বারা বিভাজ্য **না** হয়, তবে $\omega^n + \omega^{2n} = -1 \implies$ মান হবে $\mathbf{-(-2)^n}$!
     - যদি $n$ সংখ্যাটি $3$ দ্বারা বিভাজ্য হয়, তবে $\omega^n + \omega^{2n} = 1 + 1 = 2 \implies$ মান হবে $\mathbf{2 \cdot (-2)^n}$!
৩. **সমকেন্দ্রিক বৃত্ত (Concentric Circle) নির্ণয়ের ২ সেকেন্ডের হ্যাক:**
   - প্রদত্ত বৃত্তের সমীকরণের $x^2 + y^2 + 2gx + 2fy$ অংশ **হুবহু অপরিবর্তিত** রেখে শুধু ধ্রুবক পদ $c$ পরিবর্তন করবে! $(x_1, y_1)$ বিন্দুগামী হলে $c = -(x_1^2 + y_1^2 + 2gx_1 + 2fy_1)$।

##### ৩.৩ Engineering to DU Written Transfer (ঢাবি লিখিত পরীক্ষার জন্য সেরা ৫টি কনসেপচুয়াল প্রশ্ন ও সমাধান)

**প্রশ্ন ১:** $3x + ky - 1 = 0$ রেখাটি $x^2 + y^2 - 8x - 2y + 4 = 0$ বৃত্তকে স্পর্শ করলে $k$-এর মান নির্ণয় কর।  
**সমাধান:**  
- প্রদত্ত বৃত্তের সমীকরণ: $x^2 + y^2 - 8x - 2y + 4 = 0$।  
  এর কেন্দ্র $C(4, 1)$ এবং ব্যাসার্ধ $r = \sqrt{4^2 + 1^2 - 4} = \sqrt{16 + 1 - 4} = \sqrt{13}$ একক।  
- শর্তমতে, $3x + ky - 1 = 0$ রেখাটি বৃত্তটিকে স্পর্শ করে, তাই কেন্দ্র $(4, 1)$ হতে রেখাটির লম্ব দূরত্ব ব্যাসার্ধের সমান হবে:  
  $$\frac{|3(4) + k(1) - 1|}{\sqrt{3^2 + k^2}} = \sqrt{13} \implies \frac{|k + 11|}{\sqrt{9 + k^2}} = \sqrt{13}$$  
- উভয়পক্ষে বর্গ করে পাই:  
  $$(k + 11)^2 = 13(9 + k^2) \implies k^2 + 22k + 121 = 117 + 13k^2$$  
  $$\implies 12k^2 - 22k - 4 = 0 \implies 6k^2 - 11k - 2 = 0$$  
  $$\implies 6k^2 - 12k + k - 2 = 0 \implies (k - 2)(6k + 1) = 0 \implies k = 2, -\frac{1}{6}$$

**প্রশ্ন ২:** পোলার সমীকরণ $r^2 - 4\sqrt{3}r\cos\theta - 4r\sin\theta + 15 = 0$ দ্বারা নির্দেশিত বৃত্তটির কার্তেসীয় সমীকরণ, কেন্দ্র ও ব্যাসার্ধ নির্ণয় কর।  
**সমাধান:**  
- আমরা জানি, কার্তেসীয় ও পোলার স্থানাঙ্কের সম্পর্ক: $x = r\cos\theta, y = r\sin\theta$ এবং $r^2 = x^2 + y^2$।  
- প্রদত্ত সমীকরণে মান বসিয়ে পাই কার্তেসীয় সমীকরণ:  
  $$x^2 + y^2 - 4\sqrt{3}x - 4y + 15 = 0$$  
- সমীকরণটিকে $x^2 + y^2 + 2gx + 2fy + c = 0$-এর সাথে তুলনা করে পাই:  
  $g = -2\sqrt{3}, f = -2, c = 15$।  
- অতএব, বৃত্তটির কেন্দ্র $(-g, -f) = (2\sqrt{3}, 2)$।  
- এবং ব্যাসার্ধ $r = \sqrt{g^2 + f^2 - c} = \sqrt{(-2\sqrt{3})^2 + (-2)^2 - 15} = \sqrt{12 + 4 - 15} = \sqrt{1} = 1$ একক।

**প্রশ্ন ৩:** যদি $z = x + iy$ হয় এবং $|z - 2i| = 2|z - 1|$ হয়, তবে সঞ্চারপথের সমীকরণ নির্ণয় কর এবং সঞ্চারপথটির প্রকৃতি, কেন্দ্র ও ব্যাসার্ধ উল্লেখ কর।  
**সমাধান:**  
- দেওয়া আছে, $z = x + iy$ এবং $|z - 2i| = 2|z - 1|$।  
- মান বসিয়ে পাই:  
  $$|x + iy - 2i| = 2|x + iy - 1| \implies |x + i(y - 2)| = 2|(x - 1) + iy|$$  
  $$\implies \sqrt{x^2 + (y - 2)^2} = 2\sqrt{(x - 1)^2 + y^2}$$  
- উভয়পক্ষে বর্গ করে পাই:  
  $$x^2 + y^2 - 4y + 4 = 4(x^2 - 2x + 1 + y^2) = 4x^2 + 4y^2 - 8x + 4$$  
  $$\implies 3x^2 + 3y^2 - 8x + 4y = 0 \implies x^2 + y^2 - \frac{8}{3}x + \frac{4}{3}y = 0$$  
- এটি একটি **মূলবিন্দুগামী বৃত্তের সমীকরণ**, যার কেন্দ্র $\left(\frac{4}{3}, -\frac{2}{3}\right)$ এবং ব্যাসার্ধ $r = \sqrt{\left(\frac{4}{3}\right)^2 + \left(-\frac{2}{3}\right)^2} = \frac{\sqrt{20}}{3} = \frac{2\sqrt{5}}{3}$ একক।

**প্রশ্ন ৪:** দেখাও যে, $\sqrt{i} + \sqrt{-i} = \pm\sqrt{2}$।  
**সমাধান:**  
- আমরা জানি, $2i = 1 + 2i + i^2 = (1 + i)^2 \implies i = \frac{1}{2}(1 + i)^2 \implies \sqrt{i} = \pm\frac{1}{\sqrt{2}}(1 + i)$।  
- আবার, $-2i = 1 - 2i + i^2 = (1 - i)^2 \implies -i = \frac{1}{2}(1 - i)^2 \implies \sqrt{-i} = \pm\frac{1}{\sqrt{2}}(1 - i)$।  
- অতএব, একই চিহ্ন গ্রহণ করে যোগ করলে:  
  $$\sqrt{i} + \sqrt{-i} = \pm\frac{1}{\sqrt{2}}(1 + i + 1 - i) = \pm\frac{2}{\sqrt{2}} = \pm\sqrt{2} \quad (\text{প্রমাণিত})$$

**প্রশ্ন ৫:** প্রমাণ কর যে, $\cos 20^\circ \cos 40^\circ \cos 60^\circ \cos 80^\circ = \frac{1}{16}$।  
**সমাধান:**  
- আমরা জানি, $\cos\theta \cos(60^\circ - \theta) \cos(60^\circ + \theta) = \frac{1}{4}\cos 3\theta$।  
- এখানে $\theta = 20^\circ$ বসালে:  
  $$\cos 20^\circ \cos(60^\circ - 20^\circ) \cos(60^\circ + 20^\circ) = \frac{1}{4}\cos(3 \times 20^\circ)$$  
  $$\implies \cos 20^\circ \cos 40^\circ \cos 80^\circ = \frac{1}{4}\cos 60^\circ = \frac{1}{4} \times \frac{1}{2} = \frac{1}{8}$$  
- অতএব, বামপক্ষ $= (\cos 20^\circ \cos 40^\circ \cos 80^\circ) \cdot \cos 60^\circ = \frac{1}{8} \times \frac{1}{2} = \frac{1}{16}$ (প্রমাণিত)।

#### ৪. ট্র্যাপ ব্রেকার ও স্টুডেন্ট ভুল বিশ্লেষণ (Trap Breaker & Error Analysis)

১. **ট্র্যাপ-০১: $ax^2 + ay^2 + \dots = 0$ বৃত্তে $a$ দিয়ে ভাগ না করে কেন্দ্র ও ব্যাসার্ধ বের করা**
   - **ভুল:** $2x^2 + 2y^2 - 4x + 8y - 8 = 0$ বৃত্তের কেন্দ্র $(2, -4)$ দাগানো!
   - **কৌশল:** কেন্দ্র ও ব্যাসার্ধ বের করার আগে **অবশ্যই $x^2$ ও $y^2$-এর সহগ ($2$) দিয়ে পুরো সমীকরণকে ভাগ করে $x^2 + y^2 - 2x + 4y - 4 = 0$ বানিয়ে নেবে!** সঠিক কেন্দ্র $(1, -2)$ এবং ব্যাসার্ধ $\sqrt{1 + 4 - (-4)} = 3$।

২. **ট্র্যাপ-০২: স্পর্শকের দৈর্ঘ্যের সূত্রেও সহগ $a$ দিয়ে ভাগ না করা**
   - **ভুল:** $(x_1, y_1)$ বিন্দু থেকে $3x^2 + 3y^2 - 6x + 12y - 9 = 0$ বৃত্তে স্পর্শকের দৈর্ঘ্য বের করার সময় সরাসরি $\sqrt{3x_1^2 + 3y_1^2 - \dots}$ বসিয়ে দেওয়া।
   - **কৌশল:** স্পর্শকের দৈর্ঘ্য $L = \sqrt{S_1}$ সূত্রেও **$x^2$ ও $y^2$-এর সহগ অবশ্যই $1$ হতে হবে**! আগে $3$ দিয়ে ভাগ করবে, তারপর বিন্দু বসাবে।

৩. **ট্র্যাপ-০৩: মুখ্য আর্গুমেন্টে $-\pi + \alpha$ এবং $\pi + \alpha$ গুলিয়ে ফেলা**
   - **ভুল:** ৩য় চতুর্ভাগের জটিল সংখ্যা $-1 - \sqrt{3}i$-এর মুখ্য আর্গুমেন্ট $\pi + \frac{\pi}{3} = \frac{4\pi}{3}$ ($240^\circ$) দাগানো।
   - **কৌশল:** মুখ্য আর্গুমেন্টের সীমা হলো $-\pi < \theta \le \pi$ ($-180^\circ$ থেকে $+180^\circ$)। তাই ৩য় চতুর্ভাগে মুখ্য আর্গুমেন্ট সর্বদা ঋণাত্মক: $-\pi + \alpha = -\pi + \frac{\pi}{3} = \mathbf{-\frac{2\pi}{3}}$ ($-120^\circ$)। (যদি অপশনে $-\frac{2\pi}{3}$ না থেকে $\frac{4\pi}{3}$ থাকে, তবেই কেবল সাধারণ আর্গুমেন্ট হিসেবে $\frac{4\pi}{3}$ দাগাবে)।

৪. **ট্র্যাপ-০৪: বৃত্তের সমীকরণে ডানপাশে ধ্রুবক থাকলে চিহ্ন ভুল করা**
   - **ভুল:** $x^2 + y^2 - 6x + 8y = 24$ সমীকরণে $c = 24$ ধরে $r = \sqrt{9 + 16 - 24} = 1$ বের করা!
   - **কৌশল:** ধ্রুবক পদ বামপাশে আনলে সমীকরণটি হয় $x^2 + y^2 - 6x + 8y - 24 = 0$, তাই এখানে $c = -24$ এবং সঠিক ব্যাসার্ধ $r = \sqrt{9 + 16 - (-24)} = \sqrt{49} = 7$!

৫. **ট্র্যাপ-০৫: $\sin\theta$ বা $\cos\theta$-এর মানের সীমা লঙ্ঘন**
   - **ভুল:** ত্রিকোণমিতিক সমীকরণ সমাধান করে $\sin\theta = 2$ বা $\cos\theta = -\frac{3}{2}$ গ্রহণ করা।
   - **কৌশল:** বাস্তব কোণ $\theta$-এর জন্য সর্বদা $-1 \le \sin\theta \le 1$ এবং $-1 \le \cos\theta \le 1$।
